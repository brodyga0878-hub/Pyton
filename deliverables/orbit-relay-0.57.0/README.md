# Орбитальный рейс 0.57.0

Сборка Android ARM64, код 82. APK использует прежние пакет и тестовый ключ. Сохранения 0.56.0 загружаются с прежними складами, грузами и маршрутом игрока. Для уже построенной колонии расписание новых рейсов начинается с сохранённого времени.

После ввода Форпоста Вереска в строй его снабжает шаттл из Кромки. Медикаменты доставляются в Вереск, лёд уходит обратным рейсом. Когда построена станция Предела, второй шаттл возит микросхемы из Вереска и привозит обратно кристаллы. Отправление, гиперпереход, прибытие и объём груза видны в «Бирже» → «Снабжение» в обоих портах маршрута.

Проверены оба открытия станций через строительный контракт, движение грузовика в двух системах, заполненный склад, смена власти и повторная загрузка во время перевозки. Проверка на Galaxy S23 Ultra предстоит.

# Исходное ядро дальних перелётов — 17 ноября 2026 года

Контрольная точка исходников. Устанавливаемая игра остаётся 0.28 / code 53;
новые ядра ещё не подключены к Main. Это не новый APK и не полный дальний маршрут.

В исходники добавлены DOS-банк систем отсчёта F595/F604/F605/F606,
угловое движение F585/F611 с нормализацией F1520, исходный приём счётчиков
времени и общий raw-владелец с атомарными командами и проверяемым cold restore.
Полные F570/F866/F1418/F597 и обработчики событий остаются следующими частями.

Для полного проекта нужны оба ZIP, каждый меньше 32 МиБ:

1. [Полный архив основы 0.28](https://raw.githubusercontent.com/brodyga0878-hub/Pyton/f6d802e5f34f735eef91fdc2670bc8850443511a/deliverables/0.28.0-native-station-alpha1/StarFrontier-0.28.0-native-station-source.zip) — 33 543 341 байт.

Сначала распакуйте основу, затем обновление в ту же родительскую папку,
разрешив замену совпадающих исходных файлов. Оба используют папку
`StarFrontier-0.28.0-source/`. Файл `SOURCE_UPDATE_MANIFEST.json` расположен
рядом с папкой проекта. Одно обновление без основы не является полным проектом.
Для дальнейшей работы в другом чате сохраните оба ZIP.

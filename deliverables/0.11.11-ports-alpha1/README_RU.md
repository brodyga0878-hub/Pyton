# StarFrontier 0.11.11 — исходные положения портов

Нативный ARM64 APK, код 33, прежняя тестовая подпись. Новые полёты используют исходные центры 17 орбитальных портов в отдельном невращающемся локальном кадре. Старые v1/v2 сохраняют свои параметры и кадры. Исправлены переходы с поверхности и сохранение после перелёта. Форма станции, коридор, службы и живая SI-гравитация пока адаптированы.

ZIP содержит полный текущий исходный проект без готовых поставок и каталога отчётов; размер меньше 32 МиБ для прикрепления к чату. Включены 51 карта материалов, исходные JSON, тесты и независимые native-эталоны. Git-коммит, SHA-256 и точные границы указаны в manifest.json.

55 103 проверки в 28 наборах прошли без ошибок. Установка и длительная работа на физическом S23 Ultra ещё не проверены; это тестовая альфа.

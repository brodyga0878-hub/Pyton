# StarFrontier 0.14.0 — сведения о системах

Нативный Android ARM64 кандидат **0.14.0-system-info-alpha1 / code 39**.
Открытие: «Система» или «Карта» → «Сведения»; есть вход из бортового компьютера.
Классическая нижняя панель полёта сохранена.

Добавлены общее описание, население/политика, импорт/экспорт/запреты и
карточки тел с исходными числовыми значениями, периодами и космопортами.
Переведены 358 строк этого раздела, включая 25 непустых историй; 19 исходных
пустых записей сохранены. DOS-метаданные информации отделены от JJFFE
генерации игрового мира. Неизвестная система скрывает планетные данные.

Просмотр сохраняет физическое состояние, время, текущий мир и цель полёта.
Возврат восстанавливает тот же экземпляр карты с её ракурсом и прогнозом.
Ускорение времени прерывается по прежнему правилу модальных экранов.
Торговая сводка является информацией; полноценный рынок 33 товаров этим
модулем не реализован. Полный исходный интерпретатор и все механики FFE
остаются незавершёнными; это альфа реконструкции, не полный выпуск.

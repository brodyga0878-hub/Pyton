# Орбитальный рейс 0.34.0

В этом обновлении появилась посадка на астероид «Осколок», отделяемый добывающий модуль и продажа руды в порту. Посадка доступна вручную и на автопилоте. Возвращение модуля загружает руду в трюм и разрешает взлёт.

- Тестовая сборка для Android ARM64, код 59. [APK](OrbitRelay-0.34.0-arm64.apk)
- Полный проект для Godot 4.6. [Исходники ZIP](OrbitRelay-0.34.0-source.zip)
- Кадры из рейса на астероид. [Подлёт](asteroid-approach.png) · [Бурение](asteroid-mining.png)

Вылетите из порта, выберите «Осколок» кнопкой «Цель» и включите «Авто». После посадки разверните модуль, дождитесь окончания бурения и заберите его. Продайте руду после стыковки в порту.

Пакет и тестовая подпись совпадают с версией 0.33, сохранения мигрируют при загрузке. В Godot прошли 59 проверок нового маршрута и два прежних набора. Графический прогон завершился продажей 12 единиц руды за 240 кредитов. Запуск на физическом телефоне ещё предстоит. [Контрольные суммы и проверки](manifest.json)

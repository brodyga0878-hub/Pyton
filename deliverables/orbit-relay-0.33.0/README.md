# Орбитальный рейс 0.33.0

Первая тестовая сборка самостоятельной космической игры на русском. В ней есть два вращающихся порта, ручная и автоматическая швартовка, контракты в обе стороны и сохранение рейса.

- Тестовая сборка Android ARM64, код 58. [APK](OrbitRelay-0.33.0-arm64.apk)
- Полный проект для Godot 4.6. [Исходники ZIP](OrbitRelay-0.33.0-source.zip)
- Кадры из игрового рейса в Godot. [Подлёт](flight.png) · [Стыковка](docked.png)

Возьмите контракт в порту, нажмите «Старт» и включите «Авто». После стыковки сдайте груз. В полёте можно сменить цель и вернуться к ручному управлению. Кнопка «Отчёт об ошибке» сохраняет ZIP с состоянием рейса и журналом.

APK собрана из распакованного архива исходников. Проверены рейс туда и обратно, условия ручной швартовки, холодная загрузка, касания в интерфейсе и содержимое ZIP отчёта. APK имеет тестовую подпись и собственный пакет `org.orbitrelay.game`. Проверка на физическом Android остаётся впереди. [Сведения о файлах и проверках](manifest.json)

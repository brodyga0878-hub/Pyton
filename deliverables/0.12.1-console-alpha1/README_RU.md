# StarFrontier 0.12.1 — локальная альфа с классической консолью

Готовы Android ARM64 APK, переносимые исходники и пять настоящих кадров
Main. Файлы подготовлены локально; отправка в GitHub не выполнялась.
Новых проверенных HTTPS-ссылок этого выпуска пока нет.

## Состав

- `StarFrontier-0.12.1-console-arm64.apk` — настоящий игровой проект,
  версия 0.12.1-console-alpha1 / code 35, пакет org.starfrontier.rebuild.
- `StarFrontier-0.12.1-console-source.zip` — точный исходный Git-коммит,
  код, ресурсы, тесты, fixtures, документы и история восстановления; менее 32 МиБ.
- `manifest.json` и `SHA256SUMS` — размеры, SHA-256, область проверок.
- `screenshots/` — пять кадров настоящей сцены; desktop GLES, без монтажа.
- `logs/`, `validation-final.json`, `android-verification.json` и
  `source-archive-verification.json` — отдельные доказательства.

## Что работает

Новая нижняя серая консоль, боковые банки 12 команд, красный пространственный
сканер реальной цели, масштаб±, сведения о корабле/трюме/оснащении,
переключение нынешнего режима управления, доступ к поверхности и пауза.
Камеры вперёд/назад/внешний вид меняют представление, сохраняя ориентацию
корабля. Принятая основа миров/доков/поверхности и старые сохранения
сохранены. Полётный интерфейс ещё не воспроизводит каждую функцию FFE.

MB4 представлен отдельным проверенным ядром записи: недельная выработка,
накопитель, запрос загрузки/возврата и snapshot/restore. В Main физическая
добывающая установка ещё не подключена. Посадки на все астероиды/кометы,
звёздный fuel scoop, исходные шасси/тепло/оснащение остаются развитием.
Исследования и конкретные границы находятся в документации исходного ZIP.

## Проверки

17 уникальных свежих наборов / 47 037 проверок / 0 ошибок: финальные 15 UI/Main
наборов (1372 проверки) и два независимых standalone набора MB4 (45 441) и
астероидной геометрии (224). Исторический итог 0.12.0 не прибавляется.
Отдельно — 24 Python-теста проверяющего инструмента упаковки.

Настоящий APK проверен: ARM64-only, minSDK 24 / targetSDK 36, nondebuggable,
прежний TEST-сертификат, 16 КиБ ZIP/ELF, без лишних разрешений, 51 карта.
Это не публикация для магазина и не проверка физического S23 Ultra.
Снимки и их время не являются измерением FPS/нагрева телефона.

Точный ZIP прошёл CRC, свежий изолированный импорт и обычный запуск
World v4 с сохранением/загрузкой: 10 проверок / 0 ошибок. Эти 10 не прибавлены
к целевому итогу 17 наборов. Ключ подписи, SDK, кеши и готовые поставки в
исходный ZIP не включены.

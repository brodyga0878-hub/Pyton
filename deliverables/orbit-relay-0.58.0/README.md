# Орбитальный рейс 0.58.0

Сборка Android ARM64, код 83. APK использует прежние пакет и тестовый ключ. Формат сохранений совпадает с 0.57.0.

При ручном заходе на твёрдое тело прибор показывает высоту, уклон, скорость снижения, снос и направление носа относительно движущегося грунта. Вне площадки метка следует рельефу. Зелёный цвет показывает готовность к посадке. После посадки верните добывающий модуль на корабль, чтобы снова стала доступна кнопка взлёта.

Сохранения, сделанные в момент погрузки или выгрузки, загружаются с учётом округления игрового времени. Партия продолжает рейс или выгружается один раз в соответствии с сохранённым состоянием.

В расчётных прогонах проверены 336 участков на 14 твёрдых телах. На 279 участках выполнена посадка, добыча, возвращение модуля и взлёт на резервной тяге с пустым баком. Посадка на 57 крутых участках была отклонена. Сборка проверена инструментами Android. Проверка на Galaxy S23 Ultra предстоит.

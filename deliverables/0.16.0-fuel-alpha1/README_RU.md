# StarFrontier 0.16.0 — реактивное топливо и топливозаборник

Нативный Android ARM64 кандидат **0.16.0-fuel-alpha1 / code 41**.
Отдельный реактивный бак, ручная и автоматическая заправка из трюма,
сбор водорода у звёзд/газовых гигантов и три устройства в доковых службах.
Классическая нижняя консоль сохранена.

В «Оснащении» доступны бак, «Заправить бак из трюма», переключатель
автозаправщика и оборудование. Для сбора нужны топливозаборник, подходящая
исходная атмосфера, место в трюме и фактическая скорость не ниже 875 м/с.
Инерционный режим позволяет разогнаться выше заданных на рычаге 600 м/с.
Водород сначала поступает в трюм; бак и гиперпереход расходуют его отдельно.

Сохранения 0.15.0 с исходным гипердвигателем получают новый вложенный
топливный сеанс по начальному профилю корабля; прежние товары/маршрут
сохраняются. Старые v1/v2 продолжают прежние правила до явного перехода
в доке через «Оснащение» → «Исходный гипердвигатель · перейти».

# StarFrontier 0.11.10 — исходные орбиты

Нативный ARM64 APK, код 32, прежняя тестовая подпись. Новые полёты используют исходные орбиты JJFFE для 92 небесных тел в 11 системах; старые сохранения остаются на прежнем расчёте. Радиусы, массы, гравитация и вращение поверхности пока адаптированы. Полный выпуск FFE и физический S23 Ultra не проверены.

ZIP содержит полный текущий исходный проект без готовых поставок и каталога отчётов; размер меньше 32 МиБ для прикрепления к чату. Включены 51 карта материалов, исходные JSON, тесты и независимые native-эталоны. Git-коммит, SHA-256 и точные границы указаны в manifest.json.

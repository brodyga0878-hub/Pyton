# Орбитальный рейс 0.54.0

Сборка Android ARM64, код 79. Формат сохранений совпадает с 0.53.0. APK использует прежние пакет и тестовый ключ.

При ручном подлёте к выбранному доку прибор показывает расстояние по оси, смещение, скорость и ошибку крена. Направляющие двигаются и вращаются вместе со станцией. Подведите корабль к створу и нажмите «Крен дока», чтобы следовать вращению станции. Ручной крен отключает помощник. Тяга, курс и тормоз доступны во время синхронизации.

Автопилот завершает подход в пределах 2,7 м от замка при относительной скорости до 3 м/с. Проверены 168 подходов к семи портам при разных орбитальных положениях и на резервной тяге. В этой проверке все заходы завершились без повреждений. Штатные тесты покрывают ручную швартовку, оба направления вращения и отмену помощника. Проверка на Galaxy S23 Ultra предстоит.

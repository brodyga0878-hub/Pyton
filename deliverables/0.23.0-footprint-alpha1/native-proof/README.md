Reproduce from the project root on Linux x86_64 with Python3 and GNU `as`/`ld`:

```sh
python validation/footprint-2026-11-14/native-proof/rebuild_source_footprint_native.py
python validation/footprint-2026-11-14/native-proof/validate_source_footprint_native.py
```

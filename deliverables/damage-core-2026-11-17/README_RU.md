# Исходное ядро повреждений и слотов объектов — 17 ноября 2026 года

В проект добавлены отдельно проверяемые процедуры исходных повреждений,
общего RNG, управления слотами и переносимого состояния. Реальные границы
и внешние зависимости перечислены в `docs/SOURCE_DAMAGE_CORE_RU.md`
и текстовых native-доказательствах внутри проекта.

Это исходники отдельно проверяемого ядра. Новые модули ещё не подключены
к Main; устанавливаемая игра остаётся **0.28 / Android code 53**.
Полные эффекты F942/F952, VM событий и тела обработчиков модулей ещё
требуют переноса; ветвь уничтожения сейчас использует явное продолжение.
Полный мировой планировщик, эфемериды F866, дальний автопилот F597,
подключение общего цикла и окончательная проверка Android остаются
следующими блоками. S23 Ultra, графика и FPS этим checkpoint не проверялись.

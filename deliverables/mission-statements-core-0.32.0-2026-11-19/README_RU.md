# Исходное ядро команд миссий и создания объектов — 19 ноября 2026 года

В проект добавлены отдельно проверяемые процедуры F39/F40 создания объектов,
интерпретатор команд F41 и новое составление VM с владельцем состояния. Реальные границы
и внешние зависимости перечислены в `docs/SOURCE_MISSION_STATEMENTS_RU.md`
и текстовых native-доказательствах внутри проекта.

Это исходники отдельно проверяемого ядра. Новые модули ещё не подключены
к Main; исходная версия — **0.32.0-statements-alpha1 / Android code 57**.
Ресурсные таблицы извлечены из байтов оригинальной DOS-версии; отличия
позднего JJFFE сохраняются отдельно. F39 возвращает скалярное слово,
F40 создаёт объект; это не строковые помощники. F41 связывается с прежними
выражениями, присваиваниями, задачами и событиями. Форматирование F1344
и неподтверждённые действия мира остаются явными внешними зависимостями. Исходные jump-таблицы и их адреса проверяются
отдельно от текстовой схожести assembly. S23 Ultra, графика и FPS этим блоком
не проверялись.

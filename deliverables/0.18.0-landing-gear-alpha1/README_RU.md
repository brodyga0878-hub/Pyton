# StarFrontier 0.18.0 — управляемые шасси

Нативная Android ARM64 альфа **0.18.0-landing-gear-alpha1 / code 43**.
Добавлены исходный F1008 и выбранная ветвь F1056: команда выпуска/уборки,
постепенное движение опор, предупреждение высокой скорости и блокировка
переключения в припаркованном состоянии. На нижней консоли появилась
кнопка шасси; все прежние кнопки сохранены. Три существующие модели корабля
отображают действительное положение опор.

Шасси сохраняют промежуточное положение и точные исходные часы. Старый
файл без нового состояния получает выпущенные шасси после посадки/в доке,
убранные в полёте; уже существующее состояние не сбрасывается.
Автопосадка запрашивает выпуск и ждёт готовности. При мягком касании
с убранными опорами применяется явно адаптированный зазор 0.05м:
корабль остаётся в полёте, «Подъём» и отход работают. Прежний закон
повреждений при жёстком ударе сохранён. Полный исходный F575 пока не подключён.

Исправлено подключение флага нагрева: исходный E9&2 означает запрос уборки;
историческое имя thermal.gear_down не означает физически выпущенные опоры.

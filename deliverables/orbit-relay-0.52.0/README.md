# Орбитальный рейс 0.52.0

Сборка Android ARM64, код 77. APK использует прежние пакет и тестовый ключ. Формат сохранений совпадает с 0.51.0.

В полёте откройте «Отчёт» и нажмите «Поделиться ZIP». Андроид откроет выбор приложения. Отправку в выбранном приложении подтверждает игрок. В архив входят версия, состояние полёта и последние события. «Сохранить ZIP» записывает архив в «Загрузки → OrbitalRelay» на Android 10 и новее, если система разрешила запись. «Копировать текст» доступно в том же окне.

Проверены создание и чтение ZIP, касания в окне отчёта, отказ записи и обработка сбоев передачи через тестовый адаптер Android. Упаковщик исправляет совпадавшие адреса двух компонентов Android. Установка и системное меню на Galaxy S23 Ultra требуют проверки на устройстве.

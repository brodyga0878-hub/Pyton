# StarFrontier0.20.0 — сферическая проверка и диагностика

Нативная Android ARM64 TEST-альфа **0.20.0-spherical-contact-alpha1 / code 45**.
Полностью перенесена DOS F577. Отдельно проверена чистая цепочка
F575 coarse/header → F577 → прежний ответ игрока для простого выбранного
родителя. Живая Main добавляет только source_spherical_probe в журналы
и отчёт. Это диагностический конверт: envelope_only=true,
response_applied=false, объектного банка нет. Новая физическая ветка
столкновений не включается. Рельеф, посадка, HP, графика и управление
сохраняют прежнее поведение0.19.

Возврат F577:0 — внутренний кандидат,−1 — снаружи или равенство.
Флаг2 не означает удар/посадку; DATA8703/4 — расстояние от центра,
не AGL. Внутренний результат не пишет вид контакта/предыдущую высоту/HP.
DOS в неположительной ветви использует body inner140 +parent outer138;
JJFFE inner140 учитывается только отдельным контрфактическим контролем.
Положительная ветвь использует два внешних64-битных радиуса.

инициализированных простых моделей. У модели0 F1533 пропускает

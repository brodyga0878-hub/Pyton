# StarFrontier 0.21 — исходный природный контакт

Нативная Android ARM64 TEST-альфа **0.21.0-natural-contact-alpha1 / code 46**.
F576/F579 и природная F582/F581/F1876 используют реальные положительные
радиусы Eagle, Cobra и Shuttle, включая обе смещённые записи Cobra и одну
Shuttle. Поддержаны природные модели117..148; общий collision VM вне этого
контракта. Проверено 993 новых независимых DOS-случаев.

Новая standalone-композиция передаёт настоящие globals в прежний F575
только для поддержанного kind1; успешный nohit не создаёт response.
Это композиционная проверка отдельно доказанных kernels, а не новый
единый native F576→F575 oracle. HP/RNG здесь не исполняются.

Main добавляет только read-only `source_natural_probe` в периодические
журналы и ZIP отчёта. Авторский центр, ориентация, исходный UID и настоящие
дочерние объёмы; globals изолированы и не означают историю банка мира.
`diagnostic_only=true`, `response_applied=false`. Прежняя посадочная физика
сохранена: source F581 и видимую сетку ещё требуется согласовать по высоте.

# Орбитальный рейс 0.56.0

Сборка Android ARM64, код 81. APK использует прежние пакет и тестовый ключ. Сохранения 0.55.0 загружаются вместе с ранее выбранным прямым курсом.

Откройте «Галактику», выберите известную систему и нажмите «Проложить». Карта показывает остановки, ближайший переход, дальность и расходы топлива. Если первый прыжок укладывается в текущий запас, план учитывает этот запас. Например, с 34 единицами на борту из Гелиона можно добраться до Предела через Велар. Первый переход стоит 26 единиц, второй требует дозаправки.

После прибытия маршрут сохраняется, а привод ждёт отдельного запуска. В план можно вернуться после заправки или загрузки. Кнопка снятия маршрута доступна на карте.

Проверены расчёт маршрутов, оба прыжка с промежуточной швартовкой и заправкой, использование карты касанием и обновление старых сохранений. Проверка на Galaxy S23 Ultra предстоит.

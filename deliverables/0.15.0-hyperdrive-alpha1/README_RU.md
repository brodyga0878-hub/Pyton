# StarFrontier 0.15.0 — исходный гипердвигатель

Нативный Android ARM64 кандидат **0.15.0-hyperdrive-alpha1 / code40**.
Новая игра и карта используют исходные F833/F899–F903 для расстояния,
дальности, топлива и длительности. В доке доступны установка/снятие
двигателя, отдельные водород и военное топливо, передача топлива и сдача отходов.
Классическая нижняя панель полёта сохранена.

Старые v1/v2 загружаются с прежними правилами. Для v2: стыковка →
«Оснащение» → «Исходный гипердвигатель · перейти» → просмотр условий →
«Применить». Перед изменением создаётся обязательная независимая копия.
Топливо переносится в водород один к одному; неоднозначное оборудование,
переполнение вместимости или ошибка резервного копирования блокируют операцию.

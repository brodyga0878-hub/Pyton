# StarFrontier 0.17.0 — атмосфера, нагрев и повреждения

Нативная Android ARM64 альфа **0.17.0-atmosphere-alpha1 / code 42**.
Добавлены исходные DOS-расчёты атмосферного нагрева и торможения F1014,
урона щиту/корпусу F953 и генератора псевдослучайных чисел F1530. Игра работает без эмулятора.
Классическая нижняя консоль сохранена. В «Оснащении» появился блок
«НАГРЕВ И АТМОСФЕРА»: защита, корпус, нагрев и рекомендации.
Атмосферная защита отличается от энергетического щита.

Переход со старой 0.16 сохраняет точные проценты повреждённого корпуса,
топливо и движение. Скорость изменяется без потери исходных Q16-остатков.
В атмосфере и при опасном нагреве ускорение времени ограничено ×1.
Холодный полёт без тяги в вакууме использует проверенное сокращение
неизменяющих состояние шагов, сохраняя исходные часы и результат.

- [APK](StarFrontier-0.17.0-atmosphere-arm64.apk): 50,038,396 байт; SHA256 `8df3ed0fa1d790437bd536c16c7997ee18b263c39f462a6bad2716939e6fad63`.
- [Исходники](StarFrontier-0.17.0-atmosphere-source.zip): 30,817,760 байт; SHA256 `bf87804585f3ba90a8be2459dd8c368e8c02f97797808d68b16386bece296d29`.
  Исходный коммит `714624bba30d6359921cced42be2c1adb8d4c5bd`. ZIP: 1,421 записей / 1,268
  файлов, CRC исправен, меньше 32 МиБ.

Текущие проверки: **81,882 условий / 30
уникальных групп / 0 ошибок**; отдельно 145 Python-тестов
упаковки и 8 извлечения. 1447 новых нативных случаев сверены с инструкциями
пользовательского DOS EXE; 239 новых случаев скорости проверены по закреплённому
JJFFE. Повторно используемые 377+330 геометрических случаев не объявляются
новыми исполнениями. Исторические и повторные суммы не прибавлены.

Восемь настоящих кадров Main осмотрены: 144 условий захвата,
0 ошибок. Это программный desktop GLES/Mesa; положения наблюдателя,
атмосферный пролёт и док для установки защиты подготовлены контрольным
сценарием. Ручной подлёт, FPS и физический телефон не подтверждены.

Точный ZIP распакован отдельно: свежий импорт, изолированный обычный запуск
10/0 и настоящий Main с новой тепловой моделью
463/0. Все 1,268 исходных файлов сохранили SHA.
SDK, ключи и кеши исключены. Документы внутри ZIP отражают исходный коммит
до публикации; подтверждение HTTPS записывается отдельно.

Отдельные ядра соответствуют DOS; фиксированный вызывающий цикл 60 Гц,
телефонные системы отсчёта и локальная последовательность RNG являются
явными адаптерами. Полные F942/F952, игровая машина событий, повреждение
оборудования, переключение систем отсчёта, бой, рынки и кампания не завершены.
Неизвестная исходная высота −1 преобразуется в HUD INTMAX и не считается
атмосферой, а топливозаборник получает прежнюю исходную высоту.

APK подписан прежним TEST-сертификатом: ARM64, min SDK 24, target SDK 36,
debuggable=false, ZIP/ELF выравнивание 16 КиБ. S23 Ultra ещё не проверен.
Это альфа реконструкции; полный релиз и 100% клон пока не готовы.

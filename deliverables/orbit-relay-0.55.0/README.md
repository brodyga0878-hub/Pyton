# Орбитальный рейс 0.55.0

Сборка Android ARM64, код 80. Формат сохранений совпадает с 0.54.0. APK использует прежние пакет и тестовый ключ.

На скалах и льду видны отдельные трещины, зёрна и слои. Новые материалы корабля и станций отображают риски металла, износ краски и микрорельеф. Газовые гиганты получили структуру облачных полос и дрейф облачных слоёв по игровому времени.

В источниках лежат пять бесшовных карт 512×512, настройки их импорта без потерь и генератор `tools/generate_material_maps.py`. Карты поставляются в исходном ZIP и в импортированном виде в APK. Снимки «до» и «после» сделаны в движке с одинаковыми камерами и состоянием сцены для каждого материала.

Проверка в настольной графической среде включает смену трёх профилей и крупные планы. Проверка производительности и запуска на Galaxy S23 Ultra предстоит.

# Орбитальный рейс

Версия **0.34.0**, код сборки Android **59**. Космический симулятор на Godot 4.6 с русским интерфейсом. Пакет `org.orbitrelay.game` обновляет «Орбитальный рейс» 0.33 и читает его сохранения.

В порту возьмите контракт на доставку регуляторов охлаждения, нажмите «Старт» и включите «Авто». Корабль выйдет из зоны станции, подойдёт к створу «Тихого порта» и синхронизирует крен. После стыковки нажмите «Сдать груз». Здесь доступен обратный рейс с калибровочными датчиками.

Вручную направляйте корабль большой площадкой слева, управляйте креном малой площадкой и меняйте тягу кнопками справа. Для швартовки подойдите к центру кольца, сбросьте скорость до 5 м/с и совместите нос и крен со створом. Ручное управление или тормоз отключают автопилот.

Для добычи стартуйте из порта, выберите «Осколок» кнопкой «Цель» и включите «Авто». Для ручной посадки подойдите к отмеченной площадке, направьте к ней нос, сбросьте скорость до 4 м/с и нажмите «Посадка». На поверхности разверните добывающий модуль. Когда бурение завершится, заберите модуль и дождитесь его возвращения на борт. После взлёта руду можно продать в любом из двух портов по 20 кредитов за единицу. Трюм вмещает 24 единицы, одна добыча даёт до 12.

На компьютере работают WASD и стрелки, Q/E для крена, Shift для ускорения, пробел для тормоза, R/V для тяги, T для выбора цели, F для автопилота, Enter для старта, швартовки и посадки, M для контрактов, G для модуля, B для продажи руды и F8 для отчёта.

Прогресс сохраняется на устройстве. «Отчёт» → «Сохранить ZIP» записывает состояние рейса и недавние события. На Android 10+ игра пробует положить архив в «Загрузки → OrbitalRelay». Кнопка «Копировать текст» доступна в том же окне.

Откройте `project.godot` в Godot 4.6. Для сборки APK выберите экспорт **Android** и укажите свою подпись. Проверки из командной строки запускаются через `godot --headless --path . --script res://tests/test_flight.gd`, `test_scene.gd` или `test_asteroid.gd` из той же папки тестов. Для проверок сцены используйте отдельный каталог данных, чтобы не трогать свой рейс.

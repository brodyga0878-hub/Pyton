calculates expected height, collision arithmetic or persistent query words.

queried native source-space pose, plus four real flat inner-gate controls.

independent F576 fixture. Distinct IDs, selected-parent position, stationary

exercise more than one F576 child volume. The four flat controls prove that
the original query words remain unchanged, including opaque full 32-bit
graphics values which are never used as a query detail level.

all raw outputs and canaries. The complete source body/collider, caller and

query words are compared. Actual terrain replies resume F582, its results
resume F576, and the actual front result resumes F575 before its response.

engine. The standalone terrain bank separately covers all 37 original terrain
records, including the two-record model 116 and all terrain styles; this

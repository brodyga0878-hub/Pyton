# Проверка публикации версии 0.30

verification.json фиксирует девять полных HTTPS-загрузок точного artifact commit: APK, оба исходных ZIP, манифест и подтверждающие JSON/README. Проверены размеры/SHA, CRC и Git-комментарии ZIP. Функциональные проверки, повтор ресурсов и независимая Android-компиляция описаны в соответствующих отчётах.

verify_downloads.py — выполненный проверяющий скрипт. prepare_bundle.py запечатывает пакет после чистой проверки исходников и реальной APK. publish_docs.py обновляет четыре текущих раздела только после проверки скачиваний. Скрипты сохранены для аудита; исходные ZIP и манифест после публикации не менялись.

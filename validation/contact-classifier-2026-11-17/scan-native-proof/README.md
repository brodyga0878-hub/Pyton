# Actual source scan/classifier composition

Thirty-two source-bank cases execute the archived whole DOS F569/F570 and
frame/cache math, resume each F575 boundary through the independently verified
whole F575, actual F577 and original DOS F578, and replay that result through
the original scan. Eighty classifier calls occur in192 total native calls;
each call executes in three fresh processes and every native packet repeats
in reverse order. Four cases perform an actual rotating-frame conversion;
32 candidate records receive source cache changes.

Only the existing ELF64 observer transport is extended from72 to752 bytes:
a supplied raw response can copy both338-byte records after exact globals.
The original whole-frame instruction prefix is byte-identical to its archive.
The transport sends independently executed classifier results; Python does
not compute expected positions, velocities, frames, collision flags or damage.
The temporary executables and assembler objects are not archived.

These cases use simple original source-object flags and real F577/F578.
No generic F576 model program response is supplied. Authoritative F953 world
damage remains an exact identity observation. This proves the connected scan
kernel, not the general model VM, Main integration or Android rendering.

Run tools/rebuild_source_contact_scan_native.py --output FILE --proof-dir DIR.
The optional --exe, --asm and --data flags accept deliberately missing paths;
this composition reads only archived verified instruction sources.

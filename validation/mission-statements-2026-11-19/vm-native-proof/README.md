# Native composition with the real F41 statement caller

The final bank contains **34 actual native compositions, 180 measured child
results, 146 nested dependency calls, 35 original F41 invocations and 21 explicit
world observations**. Independent Godot verification passes **1,361 checks with
no failures**, including every case through hot execution, cold JSON,
prepare/commit and snapshot restore. All 57 report source pins are current.

F41 is executed by the proved native statement kernel. It is never supplied as
a world reply. The complete F41 proof covers 1,430 original instructions, every
code region, all 61 original DWORD dispatch targets and the actual thirteen
instruction strlen helper. The eight constituent proof sets contain 54 captured
procedure labels and 4,432 original instructions; F1345 is a ten instruction
resource-boundary anchor only. The executable constituent set therefore has
53 bodies and 4,422 original instructions. This count describes the available
proved bodies and is not a claim that every body runs in every composition.

## Persistent owner and private frames

Core21 adds an owned text buffer, a text cursor offset and the exact324-byte
original vector table to the frozen Core18. Task arenas, logical variable
allocations, event trees, market records, Root, tail and body bank retain one
shared logical identity across nested calls. Source cursor advances are
invocation-local. Each recursive F41 entry consumes its own explicitly supplied
156-byte seed and00/01 definedness mask in FIFO order.

The source frame exposes72 bytes through callee pointer windows:20 formatter
parameter bytes,48 UI packet bytes and4 outlocal bytes. Other84 scalar-spill
positions are retained as excluded transport seed witnesses. Frame receipts
record the real caller-observable bytes and masks in completion order with their
entry ordinal. Unknown bytes are never silently advertised as initialized zero.

The statement caller closes real F31/F37/F38/F52/F48 and F39/F40 dependencies.
Spawn F1510 phase and F1675 matrix helpers are native. F1344 formatting, F927
allocation, actual-DOS F1507 position and remaining world services have explicit
arguments, full Core21 before/after states, cursor binding, raw input/output
bytes and per-byte definedness. Their authored replies are inputs to the native
caller proof; no formatter, allocation, UI or world-body implementation is
claimed by accepting those replies. F39's real identity return remains visible
in its dependency receipt, while the enclosing F41 call correctly ignores EAX.

## Coverage and memory lifetime

The bank exercises literal and arithmetic evaluation; local/global/register
stores and actual event dispatch; body-name text at bank-body+0x124; ASCII and
UTF8 NUL literal byte scanning; ordered formatter parameter writes; UI packets;
partial known/unknown four-byte output masks; all eleven service arguments;
NULL and successful native spawn callers; real task allocation, initialization,
generation changes, self-cancellation and cleanup. A registered event enters
F47/F31 and recursively calls the real F41 with a second private frame.

One case executes unchanged original module2 initialization using the complete
105-definition resource image. Explicit world RNG input is kept separate from
the caller's native remainder and store arithmetic. Six complete owner
continuation edges include task creation followed by scheduler initialization,
and a six-step immutable-program chain changing locals, registers, Root tail,
body state, a keyed market and the text owner.

Successful free-after-last-read preserves the stale source task+32 token and
retires the transported bytes privately. Those bytes are never inserted back
into the live allocation map and are never replaced by NULL. A later actual
freed-variable read/write is outside the positive native corpus, and the
portable wrapper rejects it as a bounded ownership restriction without calling
it an original CPU fault.

The old expression/store adapters also exclude changing the selected buffer
extent or global base inside a suspended callback. The Godot wrapper has
additional directed retargeting controls; this native bank does not claim
universal coverage of those transitions. The reused event heap transport admits
consecutive surviving new allocation identities; transient allocate/free gaps
remain explicitly outside its profile.

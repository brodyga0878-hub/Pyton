# Выполненные части блока 0.32 — команды миссий и создание объектов

<!-- MISSION_STATEMENTS_SOURCE_PHASE_BEGIN -->
Версия **0.32.0-statements-alpha1 / code 57**. Замороженный прогон: **60 наборов / 304 172 проверок / 0 ошибок**. После исходного freeze подтверждены фактическая APK, чистая пара ZIP и полные HTTPS-загрузки; итоговые факты сохранены ниже. PREPUB внутри архивов остаётся записью исходного момента. Новые ядра остаются вне Main; необслуженные мировые/форматирующие службы имеют самостоятельные границы.
<!-- MISSION_STATEMENTS_SOURCE_PHASE_END -->

1. **Закреплена предыдущая версия.** Проверены точные freeze/summary 0.31: 585 runtime-входов, 57 наборов / 287815 проверок / 0 ошибок, 41 native-команда и три отдельных ресурсных извлечения. Новые helpers закрепляют прежние файлы не только по количествам, но и по SHA256.
2. **Уточнена роль F39/F40.** F39 возвращает входное скалярное слово; F40 создаёт объект по девяти аргументам. Ошибочная строковая гипотеза исторического плана 0.31 исправлена только в новых документах. F1344 — отдельный formatter, остающийся явной границей.
3. **Перенесено создание объекта.** Девять целых DOS-тел / 290 инструкций и 65536 байт sine-table сверены с оригиналом. Spawn использует три владельца; исходные F927/F1507 имеют типизированные продолжения. Native-банк — 674 сценария, Godot — **7340/0**.
4. **Доказана настоящая F41.** Проверены два участка тела, все 61 DWORD таблицы DATA5 и реальные цели. Семь захваченных тел содержат 1509 инструкций, F41 — 1430. F1333 инструкционно доказана, но не выполняется обычными owned-сценариями; обычный банк исполняет F41 и пять остальных помощников.
5. **Сохранены исходные кадры и маски.** У F41 11 полей контекста и отдельные invocation-кадры. Из 156 байт seed/маски действительно наблюдаемы 72: 20 formatter-параметров, 48 UI и 4 outlocal. Остальные 84 — носитель seed частных scalar-spill, не измеренные исходные байты стека. Векторы, text cursor и bank-алиасы не дублируются произвольными буферами.
6. **Проверены команды и границы.** Statements: 362 native-сценария, 490 внешних границ, все 61 табличную позицию и 256 байтов opcode; Godot — **7656/0**. Отдельно проверены две SIGSEGV-области, один ограниченный цикл и один отказ неполной строки; они не увеличивают число обычных сценариев.
7. **Составлена новая VM.** 21 постоянное поле объединяет прежние ядра и реальные Spawn/F41. Отдельный native-банк содержит 34 композиции, 180 измеренных результатов, 146 вложенных вызовов, 35 F41-кадров, 21 пакет мира и шесть зависимых переходов. Один сценарий использует полный исходный граф 105 программ; Godot VM — **1361/0**.
8. **Проверено владение переходами.** VMState разделяет prepare/commit, проверяет receipt/ревизию и воспроизводит последний переход после холодного restore. Освобождённый владелец не вставляется обратно; реальные чтения локальных/общих слов после смены контекста проверяются по месту. Циклические и чрезмерные входы отклоняются до копирования/хеша.
9. **Заморожен общий regression.** Все прежние 57 наборов сохранены; три новых дают **16357** проверок. Полный итог — **60 наборов / 304172 проверки / 0 ошибок**, 54 подробных отчёта с актуальными хешами. Runtime-freeze содержит **593** входа; изменены только две версии metadata, **583** прочих прежних и **473** прочих опубликованных игровых входа точны. Main прежний.
10. **Подготовлен воспроизводимый комплект.** Два новых source-helper и четыре delivery/document-helper поддерживают обе цепочки версий 53→57 и 56→57. Все **107** упаковочных проверок проходят, включая отказ настоящей APK56 с подменённым отчётом57. Опись содержит 44 native-команды и три неизменных ресурсных извлечения. Независимый аудит F41 повторил точный fixture с отсутствующими приватными путями и дополнительно проверил реальные PE-байты, произвольный DWORD UI и маски; эти повторы не прибавлены к regression.

Source/artifact-коммиты, размеры/SHA256 ZIP и APK, чистое восстановление и HTTPS-загрузки заполняются только после собственных проверок. ZIP строится из замороженных Git-блобов и дополняет неизменную основу 0.28. Новые ядра остаются вне Main; F1344 и оставшиеся службы мира явные. Полный мир/все миссии, физический S23 Ultra, графика и FPS этим исходным блоком не заявлены.

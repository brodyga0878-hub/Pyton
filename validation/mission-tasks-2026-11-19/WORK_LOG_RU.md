# Выполненные части блока 0.31 — 19 ноября 2026

Целевая версия — **0.31.0-tasks-alpha1 / Android code 56**. Ниже перечислены десять выполненных частей исходного блока. Дополнительный native-композиционный банк и локальный freeze завершены: **57 наборов / 287815 проверок / 0 ошибок**, 51 подробный отчёт с актуальными хешами. После исходного freeze завершены изготовление и независимая проверка APK, чистое восстановление ZIP и HTTPS-публикация; их факты сохранены отдельно ниже. PREPUB внутри замороженного ZIP остаётся записью исходного момента.

1. **Проверен авторитетный DOS-вариант.** Тела и адресные операнды сопоставлены с загруженным EXE. Независимая сверка подтвердила все 15 новых диапазонов кода/таблиц. Зафиксированы реальные отличия F37/62, F38 и F47 от позднего JJFFE; предварительные предположения исторического плана 0.30 уточнены без редактирования старой копии.
2. **Извлечён полный каталог для смены моделей.** Таблица из 466 DWORD ограничена двумя независимыми операндами F1538/F1345. Перенесены все 465 ненулевых описаний, нулевой элемент 149, связанные collision-байты, 84 физических записи и таблица масс приводов. Все 1016 диапазонов/36025 байт отдельно сверены с EXE.
3. **Перенесена F36.** Действительная замена модели существующего объекта использует исходные F1538/F1495/F1341, разрядности и порядок обновления радиусов/флагов/физических полей. Создание F1533 не подставлено вместо неё. Есть native-банк, Godot-ядро и отдельный набор проверок.
4. **Перенесена F37.** Полное тело, 67 байтов селекторов и 18 слов переходов проверены вместе. Сохранены владельцы общих/локальных слов, регистрационные ключи, массивы, cargo WORD при capacity DWORD, последовательность оборудования и рыночная запись. Внешние службы имеют точные типизированные границы.
5. **Перенесён жизненный цикл F38/F47/F52/F53.** Полные тела подтверждены native-доказательствами и Godot-контролями. Сохранены различия слота/handle, поколения, двух потоков аргументов, локальных курсоров, состояний, регистрации блока и повторного обхода F53 с условия 1. Fault-области и ограниченные отказы явно различены.
6. **Составлен общий runtime.** Core из 18 полей хранит по одному владельцу каждого состояния. Выбор задачи и IP принадлежат кадрам вызова; F31/F22/F34/F33/F44/F45/F48/F51/F36/F37 вызывают действительные ядра. Частный callback-адаптер допускает проверяемые выделение/освобождение и повторяет реальные действия реестра без удвоения порядка вызовов. Рыночная map имеет один временный буфер представления.
7. **Добавлен владелец переходов.** Prepare сохраняет рабочее состояние, commit проверяет владельца/ревизию/receipt, snapshot и restore воспроизводят последний переход. Циклические и чрезмерно глубокие данные отклоняются до копирования/хеша. Холодное декодирование нормализует числовые поля.
8. **Проведены проверки runtime с native-составлением.** Окончательный отдельный набор — 1180 проверок / 0 ошибок, 31 native-сценарий и шесть последовательных операций одного владельца. Native-составление содержит 106 измеренных переходов, 75 зависимостей, 16 ответов мира и четыре зависимых рыночных перехода; 42 исполняемых исходных тела / 2690 инструкций не включают десять отдельных инструкций F1345-якоря. Повтор NULL-fault F52 не увеличивает число уникальных fault-областей. Независимый повтор владельцев содержит 24 проверки / 0 ошибок и собственный отчёт с хешами; его число не прибавляется к regression.
9. **Подготовлены средства восстановления и публикации.** Новые помощники сохраняют старые файлы и все 11 proof-разделов, повторяют три ресурсных извлечения, проверяют обе цепочки версий до code56 и фактическую APK. Все 101 направленная проверка помощников проходят; старая APK code55 отклоняется даже при подменённом отчёте code56. Итоговый ZIP строится только из замороженных Git-блобов.
10. **Оформлены границы и следующий блок.** Контракт, аудит и верхние PREPUB-записи отделяют выполненное исходное ядро от полной VM, мировых служб, графики и Main. Сохранены воспроизводимые независимые свидетельства; [следующий план](NEXT_BLOCK_PLAN.md) посвящён настоящей F41 и дальнейшему закрытию зависимостей.

Четыре новых функциональных набора — 19534 проверки: модели 4872, записи 9651, задачи 3831 и runtime 1180. Опись runtime — 585 входов; 572 прежних входа и 473 прочих входа опубликованной игры сохранены побайтно. Общий замороженный прогон — 57 наборов / 287815 проверок / 0 ошибок; все прежние 53 набора сохранены. Количества файлов/native-команд, размеры/SHA256 ZIP и APK, source/artifact-коммиты и HTTPS-проверки подтверждены соответствующими итоговыми отчётами ниже. Новые ядра ещё не подключены к Main; полное соответствие оригинальной игре, устройство S23 Ultra, FPS и завершение всей игры не заявлены.

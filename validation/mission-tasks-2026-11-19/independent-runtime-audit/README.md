# Независимый контроль владельцев runtime

Воспроизводимый дополнительный Godot-контроль не изменяет игровые исходники и не открывает приватный EXE/листинги. Он хранится отдельно от функциональных наборов и native-композиционных доказательств; его условия не прибавляются к итоговой сумме regression.

Из корня проекта:

```sh
python validation/mission-tasks-2026-11-19/independent-runtime-audit/run.py --repo .
```

Проверяются оригинальный полный образ программы, идентичность выбранной задачи и размера её окружения, холодная нормализация, явный F41, подготовка/commit/restore, отказ циклических и глубоких входов до копирования/хеша, журнал реального F44 из вложенного F53, выделение F51 с допустимым handle0 и освобождение через F54. Runtime и все зависимости хешируются до и после выполнения; скрипт материализуется только во временной папке. `verification.json` содержит измеренный результат и SHA256 входов, `stdout.txt` — вывод.

Этот контроль выявил исправленные привязки выбранного кадра и нормализацию JSON-чисел. Он не доказывает полное тело F41, точность всех мировых служб, подключение к Main, Android/FPS либо происхождение целых DOS-процедур: для этих задач нужны соответствующие отдельные доказательства.

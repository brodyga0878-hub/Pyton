# Частично восстановленные исходники StarFrontier

Эта отдельная ветка содержит резервные копии исходных текстов, извлечённых из сохранившихся историй рабочих агентов после утраты доступа к прежней облачной среде.

[Скачать первый ZIP](https://github.com/brodyga0878-hub/Pyton/raw/refs/heads/recovery/starfrontier-2026-11-04/recovery/StarFrontier_recovered_sources_2026-11-04_checkpoint1.zip)

Первый снимок:125файлов,65опознанных исходных путей. Есть исторические версии одного файла, тесты, настройки, документы происхождения и явно обозначенные неполные фрагменты. Подробный список и хеши — в recovery/MANIFEST-checkpoint1.json и внутри ZIP.

Это **не полный проект и не готовая игра**. Прежний APK и исходный архив полной контрольной точки0.10.8 не найдены. Основные недостающие модули перечислены в README_RU.md внутри ZIP.

Повторно пройдены144аналитические проверки обработки столкновений и33проверки представления города на синтетической геометрии. Эти проверки не подтверждают работоспособность всей игры или Android APK.

Другие ветки репозитория, содержащие Genewars, при создании этой ветки не изменялись. По мере извлечения сохранившихся текстов здесь могут появиться дополнительные архивы восстановления.

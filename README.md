# Звёздный рубеж — восстановление StarFrontier

Ветка `development/starfrontier-rebuild` содержит **новую запускаемую основу** нативного Android-проекта на Godot 4.6.3. Она собрана из частично восстановленных исторических модулей, повторно извлечённых исходных данных FFE и заново написанного недостающего кода. Полный прежний проект и APK версии 0.10.8 не найдены.

[нижняя консоль и механика](docs/RELEASE_0_12_1_RU.md). Основа миров
[0.12.0](docs/RELEASE_0_12_0_RU.md) сохранена отдельно. Обе контрольные точки
загружены в GitHub 7 ноября 2026 года после отдельного разрешения владельца.

Новый полёт использует исходную генерацию секторов и координаты систем, полные системы, орбиты и вращение, рельеф, открытые города, станции 69 и 72–80 и подземный ангар 96. Работают сенсорный стик с независимыми пальцами, физические стыковка/вылет, посадка вне площадки, ручной подъём, автовыход на орбиту и двухслотовое сохранение. Старые миры v1/v2/v3 сохраняют прежние параметры. Интерфейс русский; Android использует ARM64 Godot без DOS/x86-эмулятора.

**Полноценная оригинальная галактическая карта ещё не перенесена:** экран
показывает список систем области 3×3 сектора, а правила топлива, дальности
и времени переходов остаются адаптированными. [Точный статус карты](docs/GALACTIC_MAP_STATUS_RU.md).

**Это восстановительная альфа, не полный перенос FFE.** Исходная F603 связана с полётом через явный мост единиц/времени, а мобильная детализация поверхности имеет отдельный контракт; полный исходный покадровый интегратор не заявлен. Реестр 57 кораблей ещё не означает 57 доступных корпусов: сохраняются три адаптированных профиля и прежняя топливная политика. Полные корабли/оснащение, экономика, ИИ, кампания, русский текстовый корпус и качество графических референсов остаются следующими работами. Физический Samsung S23 Ultra ещё не проверен; подпись APK тестовая.

Блок 10 принят, начат **блок 9 «Корабли и оборудование»**: [план](docs/BLOCK9_PLAN_RU.md), классическая консоль и исследование исходных взаимодействий. Полный парк и оснащение ещё не готовы. Итоговый прогон основы **0.12.0** — **931 938 проверок в 85 наборах, 0 ошибок**; отдельно проверены упаковка ARM64 APK и [четыре настоящих кадра Main](validation/worlds-2026-11-06/screenshots/). ## Запуск и проверка

Открыть `project.godot` в обычном Godot 4.6.3 и запустить сцену. На машине с недоступным домашним каталогом задайте доступные `XDG_DATA_HOME` и `XDG_CACHE_HOME`.

```sh
python3 tools/validate_rebuild.py
godot --headless --audio-driver Dummy --path . -- --rebuild-smoke
python3 tools/setup_android_toolchain.py
sh tools/build_android.sh --candidate
python3 tools/verify_rebuilt_android.py build/starfrontier-rebuild-arm64-alpha.apk build/android-verification.json
```

Встроенная сквозная проверка не читает и не перезаписывает пользовательский прогресс. Тесты математики и таблиц используют независимые контроли исполнения исходных процедур; это не доказательство готовности всей игры. Аппаратные FPS и нагрев нельзя определить по этим проверкам.

Сохранения этой сборки используют `starfrontier-rebuild-game-v1`. Старый полный формат и оригинальный COMMANDR пока не импортируются. В меню есть резервная копия в виде кода для сохранения вне приложения. Пакет `org.starfrontier.rebuild` устанавливается рядом с прежней версией; подпись пока тестовая.

Остались пять крупных блоков: **9 → 11 → 12 → 13 → 14**. Историческая копия, исходники и артефакты 0.12.0/0.12.1 сохранены в GitHub по разрешению владельца. Другие ветки с Genewars не изменяются.

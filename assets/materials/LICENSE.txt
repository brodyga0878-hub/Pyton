Original StarFrontier material textures and material manifest

All PNG material maps in the eight family subdirectories and the review contact
sheet were authored specifically for this project using the original generator
at tools/generate_material_textures.py. No third-party artwork is included.

To the extent possible under law, the authors dedicate these original texture
assets to the public domain under CC0 1.0 Universal (CC0-1.0).
https://creativecommons.org/publicdomain/zero/1.0/

The generator and runtime code follow the repository's code licensing terms;
this asset dedication makes no claim about other game data or original FFE IP.

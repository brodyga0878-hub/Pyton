# Проверка кнопки отчёта в настоящем Main

`tests/test_bug_report_ui.gd` проверяет реальный контроллер и его кнопки, сборщик ZIP и экспортёр. Godot4.6.3: **95 проверок,0 ошибок**, без диагностик движка и утечек. Лог текущего прогона: `/workspace/recovery/bug-report-ui-tests.log`.

```sh
XDG_DATA_HOME=/workspace/rebuild-test-state/data \
XDG_CACHE_HOME=/workspace/rebuild-test-state/cache \
godot --headless --path . --script tests/test_bug_report_ui.gd -- --rebuild-capture
```

Флаг capture отключает загрузку пользовательского полёта и автоматическую инициализацию его журнала. Тест самостоятельно запускает настоящий сборщик с каталогами `user://bug-report-ui-test-<pid>/`, пишет туда ZIP и копию экспорта, затем удаляет только свой каталог. Полёт не сохраняется в обычные слоты.

Проверены:

- вход через настоящую кнопку в обычном и графическом меню;
- видимая ошибка при неинициализированной диагностике и снятие `busy`;
- многострочное русское описание и сохранение его черновика;
- создание ZIP нажатием настоящей кнопки, метаданные выпуска и актуального полёта, журнал событий;
- все размеры и SHA-256 файлов по манифесту реально созданного архива;
- отсутствие полной копии прогресса по умолчанию и её точное JSON-содержимое после явного выбора;
- видимая неактивная кнопка повтора до первого ZIP, её немедленное включение и повторное сохранение того же архива без переоткрытия страницы;
- сохранность исходного ZIP при отмене, повторный доступ к нему, проверенная побайтовая копия и понятная ошибка пропавшего файла;
- сигналы завершения/отмены экспортёра доходят до настоящего интерфейса;
- отчёт внутри графического режима не меняет приостановленный основной полёт;
- закрытие страницы во время отложенного кадра создания не обращается к освобождённым меткам;
- уже открытый диалог блокирует повторное создание и все тестовые файлы удаляются.

Нативные callback-результаты моделируются, а проверенная запись ZIP выполняется на локальном временном пути. Это не испытание Android SAF на физическом телефоне. Штатный путь SAF подтверждается отдельно исходниками Godot; работа настоящего системного окна на S23 Ultra остаётся аппаратной проверкой.

Сам архив при отмене и ошибке сохраняется; повторное сохранение доступно сразу после первого успешного создания.


Дополнительно проверены реальные приватные слоты: открытие страницы отчёта не увеличивает поколение и не заменяет сохранение текущим диагностическим состоянием. Потеря фокуса при открытом экспортёре также не вызывает лишнее сохранение полёта. Итог текущего прогона —95 проверок.

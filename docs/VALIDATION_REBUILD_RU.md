# Проверка текущего восстановительного проекта

Общий запуск:

```bash
python3 tools/validate_rebuild.py
```

Инструмент запускает явно перечисленные тесты в отдельных headless-процессах Godot. Независимые группы исполняются максимум в трёх процессах одновременно; для каждого выделены отдельные каталоги пользовательских данных и кэша. Дерево истории не сканируется. Единственный сохранённый тест посадочных площадок загружается по точному пути и проверяет текущие `scripts/` и заново полученные нативные контроли. Исходный terrain проверяется существующим `data_validate_terrain.py` в одноразовом минимальном проекте.

Результат считается неуспешным при ненулевом коде выхода, таймауте, отсутствии единственного итогового счётчика, ненулевом числе ошибок, `SCRIPT ERROR`, `ERROR` движка или сообщении об утечке ресурсов. Анализируется весь вывод, а каждый сохранённый лог ограничен 128 КиБ с сохранением начала и конца. Исторические суммы проверок не подставляются.

Сводка создаётся в `build/validation-summary.json`, логи — в `build/validation/logs/`. Эти генерируемые файлы не включаются в исходники. В JSON указаны фактические команды, версия Godot, результат каждой группы, SHA-256 файла теста и время её выполнения. При дополнительном запуске сохраняется отдельная запись партии; отчёт не объявляется атомарным снимком всей рабочей копии.

Основные девять групп выполнены одной партией; готовые позже тесты сохранения/ввода, переходов Main, инициализации F882 и исходной ориентации добавлены отдельными партиями без повторного прогона остальных. Основная партия заняла около 10,3 с. Это время сервера, а не показатель производительности телефона.

Тест переходов получает `-- --rebuild-capture`, поэтому настоящий Main не читает и не записывает пользовательский прогресс. Проверены блокировки переходов, продолжение уже сохранённого маршрута и отказ асинхронного входа в Новую Москву при замене исходных данных во время работы загрузчика.

Новый отдельный модуль `body_initializer.gd` сравнивает полные упакованные записи с настоящим F882 в 1 424 нативных контекстах. Это следующий проверенный компонент этапа 10: он пока не подключён к живому миру и не подтверждает исходную физику, генерацию всей галактики или эфемериды. В том числе нативно подтверждена необычная исходная последовательность знакового расширения младших 16 бит произведения перед сдвигом ориентации.

Модуль `body_rotation.gd` отдельно сравнивает ориентацию с точными исходными участками инициализации F880 и обновления поворота F866, а также с F1675/F1914/F1521. Новые 1 542 нативных контекста не выдаются за потерянный старый эталон. Полная F866, анимации, орбитальные обновления и эпоха часов в эту проверку не входят; вращение живого аналитического мира не заменялось.

## Выборочная проверка

```bash
python3 tools/validate_rebuild.py --list
python3 tools/validate_rebuild.py --suite cities --suite city_runtime --summary build/cities-validation.json
```

Чтобы дополнить отчёт новым тестом в течение 24 часов, не повторяя уже прошедшие группы:

```bash
python3 tools/validate_rebuild.py --suite save_touch --extend
```

`--extend` разрешает только ранее отсутствовавшую/непрошедшую либо новую группу в отчёте того же проекта и версии Godot. Повторный запуск прошедшей группы отклоняется до старта движка. Для изменившегося кода запускают соответствующие группы заново обычной командой с отдельным отчётом; старую успешную проверку нельзя считать проверкой последующих изменений.

## Ограничения покрытия

Независимый исторический тест отдельных листовых мешей `test_source_model_mesh.gd` пока не включён: для него отсутствует `model_vertices_reference.json`. Он отмечен в JSON как **unavailable**, а не как пройденный. Текущие городские группы проверяют настоящую композицию исходных городов, но это не заменяет отсутствующий независимый эталон листовых вершин.

Общий статус отчёта — `passed_with_coverage_limitations`: выбранные тринадцать групп прошли, однако указанный исторический эталон ещё отсутствует. Оригинальные эфемериды, полная процедурная галактика, экономика/кампания, полнота русификации и законченный релиз этим отчётом не подтверждаются.

Запуск всего приложения, проверка APK и запуск на физическом Samsung S23 Ultra выполняются отдельно. Изолированные terrain-контроли не означают, что исходный рельеф уже связан с отображаемой планетой Android-игры.

# Android-сборка восстановленного проекта

Этот комплект создан заново при восстановлении проекта. Это не найденный старый APK и не подтверждение готовности всей Frontier: First Encounters.

## Подготовленная среда

Проверены и установлены в `/workspace/toolchains`:

| Компонент | Закреплённая версия | Проверка загрузки |
|---|---|---|
| Godot export templates | 4.6.3 stable, обычная версия без Mono | SHA-512 из официального `SHA512-SUMS.txt` |
| Temurin JDK | 17.0.16+8, Linux x64 | SHA-256 из официального файла выпуска |
| Android Build Tools | 36.0.0 | Контрольная сумма из официального `repository2-1.xml` |
| Android Platform Tools | 37.0.2 | Контрольная сумма из официального `repository2-1.xml` |
| Android platform package | API 35, revision 2 | Контрольная сумма из официального `repository2-1.xml`; стандартный экспорт готового шаблона не компилирует Java проекта |

TLS и настройки прокси сохраняются. Шаблоны скачиваются целиком и проверяются до извлечения только Android-файлов. Эмулятор и системные образы Android не устанавливаются.

Повторяемая установка:

```sh
python3 tools/setup_android_toolchain.py
```

Скрипт сохраняет проверенные архивы и `android-rebuild-toolchain.json` вне репозитория. При повторном запуске сначала проверяет хеши уже имеющихся архивов.

## Формат нового канала сборок

- Пакет: `org.starfrontier.rebuild`.
- Версия первого восстановления: `0.11.0-rebuild-alpha1`, код 22.
- Только `arm64-v8a`, без x86/ARM32 библиотек.
- Официальный шаблон Godot 4.6.3 фактически содержит minSDK 24 и targetSDK 36. В стандартном экспорте без Gradle параметры переопределения min/target SDK применять нельзя.
- Используется новый локальный **TEST**-ключ. Производственный ключ владельца не настроен.
- Новый пакет устанавливается рядом с прежним `org.starfrontier.flightprototype`: потерянный прежний закрытый ключ не позволяет обещать обновление старого APK поверх установленного.

Ключ находится в `/workspace/toolchains/keys/starfrontier-rebuild-test.keystore`, имеет закрытые права и не включается в Git или APK. Для долговременного канала обновлений его требуется сохранить приватно; публикация исходников не является резервной копией ключа. Последующий выпуск с ключом владельца остаётся отдельной работой этапа 14.

## Сборка проекта

```sh
sh tools/build_android.sh --candidate
python3 tools/verify_rebuilt_android.py \
  build/starfrontier-rebuild-arm64-alpha.apk \
  build/android-verification.json
```

Обёртка настраивает JDK/SDK и Godot XDG-каталоги, удаляет только прежний генерируемый выходной APK и отклоняет результат при ошибках движка либо отсутствии свежего файла. `--debug` предназначен для разработки; такой APK не проходит обычную проверку кандидата без явного `--allow-debuggable`.

Для Android в `project.godot` необходимы существующий `application/config/icon` и `rendering/textures/vram_compression/import_etc2_astc=true`. Без второй настройки Godot может выдавать пустую ошибку конфигурации. Без значка движок создаёт APK с запасным изображением, но пишет ERROR; обёртка такой результат отклоняет.

Проверка APK включает подпись TEST-канала, ожидаемый пакет/версию из текущего preset, ARM64 ELF, ZIP/ELF-выравнивание 16 КБ, CRC, отсутствие лишних разрешений и файлов разработки. Для игрового APK также обязательны оригинальные JSON моделей, реестр 57 судов, 11 ручных систем и таблица синуса. Опция `--smoke` отключает проверку игровых данных только для отдельного минимального тестового проекта и явно помечает отчёт как `toolchain_smoke_only`.

## Что реально проверено в новой среде

После отдельной проверки инструментария собран и проверен **сам игровой проект**, без опции `--smoke` проверяющего скрипта:

- версия `0.11.0-rebuild-alpha1`, код 22, пакет `org.starfrontier.rebuild`;
- minSDK 24, targetSDK 36, ARM64-only, `debuggable=false`;
- подпись TEST-канала подтверждена; ZIP и обе ELF-библиотеки прошли проверку 16 КБ;
- игровые JSON моделей, 57 корабельных записей, 11 систем и таблица синуса присутствуют;
- сетевые, микрофонные и широкие файловые разрешения отсутствуют;
- исходная история, инструменты, тесты и закрытый ключ не включены в APK.

Точный размер и SHA-256 опубликованного артефакта записаны в `deliverables/0.11.0-rebuild-alpha1/manifest.json`, подробная проверка — в `validation/rebuild-2026-11-04/android-verification.json`. Сохранённый лог `app-smoke.log` подтверждает стыковку, доставку, посадку в Новую Москву и загрузку прогресса в настоящей сцене. `render.log` и снимки подтверждают отрисовку этой сцены через desktop GLES. Это отдельные проверки, они не равнозначны запуску на Android-устройстве.

Повторная установка инструментария на сохранённых проверенных архивах также выполнена; TEST-ключ сохранился. Технический минимальный APK инструментария не публикуется как игра.

Проверки на физическом Samsung S23 Ultra, Android 17 / One UI 9, производительность, жизненный цикл и окончательная готовность к выпуску пока не подтверждены. Исходный рельеф и физика остаются частично адаптированными; полный FFE и полная русификация не заявлены.

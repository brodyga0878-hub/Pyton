# Android-сборка восстановленного проекта

Этот комплект создан заново при восстановлении проекта. Это не найденный старый APK и не подтверждение готовности всей Frontier: First Encounters.

Текущий локальный проверенный кандидат — **0.12.1-console-alpha1 / code 35**,
с классической нижней консолью и отдельным исходным ядром MB4.
[Изменения и границы](RELEASE_0_12_1_RU.md). Технические результаты 0.12.0
ниже сохраняются как отдельная проверенная контрольная точка. Новые
артефакты не опубликованы в GitHub и не имеют подтверждённых HTTPS-ссылок.

## Подготовленная среда

Проверены и установлены в `/workspace/toolchains`:

| Компонент | Закреплённая версия | Проверка загрузки |
|---|---|---|
| Godot export templates | 4.6.3 stable, обычная версия без Mono | SHA-512 из официального `SHA512-SUMS.txt` |
| Temurin JDK | 17.0.16+8, Linux x64 | SHA-256 из официального файла выпуска |
| Android Build Tools | 36.0.0 | Контрольная сумма из официального `repository2-1.xml` |
| Android Platform Tools | 37.0.2 | Контрольная сумма из официального `repository2-1.xml` |
| Android platform package | API 35, revision 2 | Контрольная сумма из официального `repository2-1.xml`; стандартный экспорт готового шаблона не компилирует Java проекта |

TLS и настройки прокси сохраняются. Шаблоны скачиваются целиком и проверяются до извлечения только Android-файлов. Эмулятор и системные образы Android не устанавливаются.

Повторяемая установка:

```sh
python3 tools/setup_android_toolchain.py
```

Скрипт сохраняет проверенные архивы и `android-rebuild-toolchain.json` вне репозитория. При повторном запуске сначала проверяет хеши уже имеющихся архивов.

## Канал сборок

- Пакет: `org.starfrontier.rebuild`.
- Локальный проверенный кандидат: `0.12.1-console-alpha1`, код 35. Предыдущая контрольная точка — `0.12.0-worlds-alpha1`, код 34. Первая версия этого восстановленного канала была `0.11.0-rebuild-alpha1`, код 22.
- Только `arm64-v8a`, без x86/ARM32 библиотек.
- Официальный шаблон Godot 4.6.3 фактически содержит minSDK 24 и targetSDK 36. В стандартном экспорте без Gradle параметры переопределения min/target SDK применять нельзя.
- Используется прежний локальный **TEST**-ключ этого канала. SHA-256 сертификата: `16f47f20a2d2aca3de1fe893ddfa01e90acf2d6b98b32ca772bb914c9ee21e25`. Производственный ключ владельца не настроен.
- Пакет устанавливается рядом с прежним `org.starfrontier.flightprototype`: потерянный прежний закрытый ключ не позволяет обещать обновление старого APK поверх установленного.

Ключ находится в `/workspace/toolchains/keys/starfrontier-rebuild-test.keystore`, имеет закрытые права и не включается в Git или APK. Для долговременного канала обновлений его требуется сохранить приватно; публикация исходников не является резервной копией ключа. Последующий выпуск с ключом владельца остаётся отдельной работой блока 14.

## Сборка проекта

```sh
sh tools/build_android.sh --candidate
python3 tools/verify_rebuilt_android.py \
  build/starfrontier-rebuild-arm64-alpha.apk \
  build/android-verification.json
```

Обёртка настраивает JDK/SDK и Godot XDG-каталоги, удаляет только прежний генерируемый выходной APK и отклоняет результат при ошибках движка либо отсутствии свежего файла. `--debug` предназначен для разработки; такой APK не проходит обычную проверку кандидата без явного `--allow-debuggable`.

Для Android в `project.godot` необходимы существующий `application/config/icon` и `rendering/textures/vram_compression/import_etc2_astc=true`. Без второй настройки Godot может выдавать пустую ошибку конфигурации. Без значка движок создаёт APK с запасным изображением, но пишет ERROR; обёртка такой результат отклоняет.

Проверка APK включает подпись TEST-канала, ожидаемый пакет/версию из текущего preset, ARM64 ELF, ZIP/ELF-выравнивание 16 КиБ, CRC, отсутствие лишних разрешений и файлов разработки. Для игрового APK обязательны исходные данные и ресурсы действующего мира: проверяющий инструмент сверяет **59 основных модулей, 2 шейдера и 21 JSON** с рабочими файлами, а также существующие карты материалов и требуемые данные реестра 57 кораблей, ручных систем и таблицы синуса. В code 35 дополнительно проверяются четыре модуля консоли (Main общий), связи 12 команд и отдельное ядро MB4 с явно неполной игровой интеграцией. Отдельные 24 Python-теста проверяют отказ при неполной или повреждённой упаковке. Опция `--smoke` отключает проверку игровых данных только для отдельного минимального тестового проекта и явно помечает отчёт как `toolchain_smoke_only`.

[Отчёт APK](../validation/console-2026-11-06/android-verification.json)

## Исторический проверенный кандидат 0.12.0

Собран и технически проверен **сам игровой проект**, без опции `--smoke` проверяющего скрипта:

- версия `0.12.0-worlds-alpha1`, код 34, пакет `org.starfrontier.rebuild`;
- minSDK 24, targetSDK 36, ARM64-only, `debuggable=false`;
- подпись прежнего TEST-канала подтверждена; ZIP и обе ELF-библиотеки прошли проверку 16 КиБ;
- действующие модули исходных миров, поверхности, контакта с опубликованным рельефом, станций и подземных портов, оба шейдера и 21 JSON присутствуют и сверены с проектом;
- сетевые, микрофонные и широкие файловые разрешения отсутствуют;
- исходная история, инструменты, тесты и закрытый ключ не включены в APK.

SHA-256 APK: **`b74c18b1a83263e2ed96720e839e6c4f99f15e3e454603e6fa87e387f292c5cc`**. Точный размер, исходный Git-коммит, SHA-256 APK/ZIP и отчёт технической проверки записаны в `deliverables/0.12.0-worlds-alpha1/manifest.json` и опубликованных рядом файлах.

Итоговый курируемый прогон содержит **931 938 проверок в 85 наборах, 0 ошибок**; его область и время отдельных запусков сохранены в `validation/2026-11-06-worlds-final.json`. Настоящий Main отдельно проверяет исходные навигацию и стыковку, закрытые ворота, сохранение/отмену/повтор вылета, ненулевое время, ангар 96 и полный ZIP-отчёт с восстановимым сохранением. Четыре настоящих кадра этой сцены сняты через desktop GLES/Mesa llvmpipe Compatibility. Они подтверждают отрисовку проверенных состояний; это не измерения FPS или нагрева телефона.

## Границы проверки

Физический Samsung S23 Ultra 12/512 ещё не проверен. Android 17 / One UI 9 указаны со слов владельца. Установка и обновление на устройстве, реальные касания, фон/возврат, Android SAF, устойчивый FPS, память и нагрев остаются непроверенными аппаратными сценариями блока 14. Техническая проверка APK и desktop GLES их не заменяют.

В новом мире применяется явный мост исходных величин и времени, а не полный оригинальный покадровый интегратор. Три адаптированных лётных профиля, ограниченные службы и топливная политика ещё требуют блока 9 и следующих работ. Полный FFE, весь исходный каталог кораблей/оснащения, экономика, ИИ, кампания, полная русификация и качество пользовательских графических референсов не заявлены.

# Новый вид орбитального окружения

Этот блок создан заново для графического образца0.11.1. Он не является извлечённой из FFE геометрией и не доказывает равенство качеству референсных кадров или производительность Android.

## Что добавлено

- `station_visual.gd`: авторский орбитальный узел с открытым кольцом, жилыми модулями, связями, техническими радиаторами, солнечными крыльями, подсветкой и русской надписью. Геометрия объединена по материалам:6 MeshInstance3D плюс Label3D.
- `space_environment.gd`: воспроизводимый декоративный астероидный пояс. Восемь форм настоящей неровной геометрии, два уровня детализации,16 групп MultiMesh.95/179/275 объектов для трёх уровней качества, включая3 близких силуэта.
- `asteroid_surface.gdshader`: каменный материал с процедурными прожилками, зерном и мелким рельефом, без внешних текстур.
- `station_solar.gdshader`: материал солнечных элементов с сеткой и металлическим отражением.
- `space_backdrop.gdshader`: самостоятельное процедурное звёздное небо с сдержанной полосой галактической пыли. Ресурс `SpaceEnvironment.sky` подключает главный контроллер.

Закрытая исходная программа, текстуры из других игр и генерация изображений для выдачи за скриншоты не использовались. Код работает на существующем GLES Compatibility renderer Godot4.6.3.

## Координаты и игровое поведение

`StationVisual.configure(quality)` строит станцию вокруг неизменённой точки докования: local(0,0,0). Вся структура располагается позади z=-110м. Главный контроллер устанавливает её узел в `ship.STATION`; радиус/скорость стыковки и движение корабля не меняются.

`SpaceEnvironment.configure(station_anchor,quality,seed)` использует координаты того же пространства. `update_view(observer)` переключает геометрическую детализацию и удаляет из отрисовки объекты дальше14500м. Перераспределение групп выполняется после перемещения наблюдателя хотя бы на40м. Нельзя переносить весь пояс к камере каждый кадр: это нарушило бы неподвижность камней в мире.

Консервативная полоса вдоль курса подхода свободна: расстояние от оси больше1.7радиуса камня+230м;фактическая максимальная геометрическая граница отдельно проверяется. Пояс — **визуальное окружение**. Он не добавляет физические столкновения, добычу или урон. Эти механики нельзя считать реализованными по наличию красивого камня.

## Проверка

```sh
godot --headless --path . --script res://tests/test_graphics_space_environment.gd
```

Текущий результат: **1136 проверок,0 ошибок**. Проверены реальные границы всей объединённой станции, неизменённый коридор стыковки, свободная ось подхода, действительная максимальная граница моделей камней, конечность трансформаций, воспроизводимость смены качества, число групп/объектов и дальнее исключение из отрисовки. Проверка логики без экрана дополняется настоящими GLES-снимками интегрированной сцены; она не измеряет FPS S23 Ultra.

После просмотра настоящего GLES-кадра высокочастотный tangent-normal заменён фильтруемым по экранным производным surface-gradient рельефом. Частоты ниже размера пикселя плавно уходят в среднее значение; крупные формы остаются геометрией. Уменьшена плотность заполнения экрана камнями, а полный угловой конус начального вида Земли отдельно очищен и проверен по275 реальным границам. Это художественная композиция стартового пояса, а не изменение исходных координат небесного тела.

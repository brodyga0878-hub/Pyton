# Современное оформление галактической карты — 0.13.1

Кандидат **0.13.1-map-alpha1 / Android code 37** меняет только визуальное
представление галактической карты. Runtime зафиксирован; настоящий ARM64
APK собран и технически проверен. Точный source ZIP и неизменяемые HTTPS-ссылки опубликованы и проверены
повторным скачиванием.
Материалы 0.13.0 остаются неизменными.

Цель дальнейшей работы — **100% соответствие выбранному оригиналу FFE**.
Этот кандидат сохраняет частичную реконструкцию и не объявляется полным
клоном. [Общий аудит соответствия](PARITY_AUDIT_RU.md) устанавливает
исходные процедуры, ресурсы, пробелы и критерии дальнейшей приёмки.

## Область изменения

Оформление `galactic_map_view.gd` получает профиль `navy-star-chart-v1`.
Новые цвета, подложки, линии и подписи относятся к представлению карты.
Передача цветов уже рассчитанного RGBA-обзора выполняется на стороне
отображения. Исходные координаты, плотность, палитровые таблицы, данные
систем и навигационные расчёты сохраняются.

Новых файлов renderer-helper, шейдеров и текстур не требуется. Сохраняются
модель карты и её данные, фоновая подготовка, перемещение, масштаб,
поиск, обработка мыши/пальцев, выбор системы и отдельное подтверждение
прыжка. Изменение внешнего вида не добавляет переход при простом выборе
звезды и не расширяет область поиска до всей процедурной галактики.

Карта системы, Main, полётная физика, планировщик времени, крен, контакт
вращающегося дока и raw-motion bridge не изменяются этим обновлением.
Ограничения [0.13.0](RELEASE_0_13_0_RU.md) сохраняются: полный исходный
renderer/инструменты, F903, автоматическая смена FOR и вся исходная физика
не объявлены готовыми.

## Проверки

Контракт упаковки code 37 дополнительно проверяет современный профиль
карты и его настоящий потребитель, скомпилированный view и хеши входов.
С точным source-коммитом 0.13.0
`e4e8e7edccdb4422124f249365dfb8c99d135bb5` сопоставляются 18 защищённых
исходных файлов/JSON и семь неотрисовочных функций карты. Это конкретная
проверка сохранения выбранных source/data-входов; она не декомпилирует
GDSC и не заменяет функциональные тесты интерфейса.

Все проверки упаковки code 36 сохраняются: 11 навигационных модулей,
22 JSON основного набора, исходные миры/орбиты/порты и пределы времени.
Текущий набор Python-проверок упаковщика прошёл **47/47**, без ошибок и
пропусков: `validation/modern-map-2026-11-07/python-packaging-tests.json`.
Он использует тестовый архив и сам по себе не подтверждает сборку APK.
Итог текущего функционального прогона — **3 257 проверок в семи уникальных
группах, 0 ошибок**: шесть интеграционных групп Main/паузы/сохранений
содержат 361 проверку; экран карты — 2 896. Это целевая регрессия данного
изменения, не повтор всех математических ядер игры. Итог 60 032 проверок
0.13.0 хранится отдельно и не прибавляется к новому результату.

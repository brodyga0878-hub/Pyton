# Кадр и предпросмотр исходного контакта — 0.24.0

Кандидат **0.24.0-contact-frame-alpha1 / Android code 49** прошёл
**50 326 условий в 23 уникальных группах / 0 ошибок**. Основа координат
и проекции выбранной исходной грани готова. Статус публикации —
**PREPUB**: исходный коммит, точный ZIP, переносимость и новые ссылки
пока не закреплены. Настоящий ARM64 TEST APK49 технически проверен. Последняя публикация — [0.23](RELEASE_0_23_0_RU.md).

В меню исходной поверхности появилась команда
**«Исходная геометрия контакта»**. Она открывает отдельный 3D-предпросмотр
с вращением и масштабированием. Для передачи данных выберите
**«Отчёт об ошибке / логи»**, соберите ZIP и прикрепите его в чат.
Просмотр не меняет камеру полёта, поверхность, физику или состояние корабля.
[Точный контракт](SOURCE_CONTACT_FRAME_RU.md).

Проверены настоящий кадр F581, исходные целые вершины и объявленная
проекция с выведенными интервалами Q31/Float32. Новый набор содержит
242 native-случая; отдельный валидатор — 400/0, Python-упаковка —
328 тестов в 12 модулях. Сняты и осмотрены четыре настоящих desktop-кадра
Main — 73 условия / 0 ошибок. Старые суммы и отдельные проверки не
прибавлены к функциональному итогу.

Это основа первого из трёх шагов контакта. Дальше — публикуемый
provider и живая история/парковка/cold restore, затем ручная
и автоматическая посадка целиком. Обычный рельеф ещё не заменён,
default v4 и живой F575 сохраняются. Это не число всех этапов до
полного релиза. S23 Ultra / Android 17 ещё не испытан; полнота клона,
русификации, FPS и магазинный релиз не заявляются.

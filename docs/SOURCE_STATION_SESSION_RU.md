# Согласованный контекст исходной станции

`source_station_session.gd` связывает выбранный исходный порт мира,
его сохраняемые двери/вращение и телефонный контроллер корабля. Контракт
`selected-source-station-session-v1` применяется только к миру
`source_jjffe_systems_v4`. Миры v1/v2/v3 продолжают прежний полёт.

## Вызовы приложения

```gdscript
var context = Session.configure_flight(ship, world, nav)
if not context.ok:
    # Контроллер показывает ошибку и приостанавливает этот шаг.
    return

# После изменения nav.elapsed_days, до ship.step:
context = Session.refresh(ship, world, nav, dt)

# Для ZIP-отчёта, без треугольников:
var report_context = Session.diagnostics(ship, world, nav)
```

Результат конфигурации содержит `ok`, `active`, `handled`, `status`.
`handled=false` обозначает старую версию мира; в ней очищается только
исходный станционный backend, прежние флаги управления сохраняются.
Для v4 флаг `source_motion_profile` выводится из версии мира, включая
наземный полёт, и не принимается из сохранения.

На v4 проверяются исходный режим навигации, идентификатор текущей
системы, конечная дата, выбранный порт и его 68-байтовая исходная запись.
Геометрия должна соответствовать реальным модели/UID этой записи,
а жёсткий кадр — пройти проверку ортонормальности Flight. Недопустимый
контекст отключает станционное столкновение, доступность служб и
станционный автопилот; старая невидимая сфера станции не подставляется.

Выбор поверхности, наземного порта или пустой точки очищает исходный
орбитальный backend. Доступность орбитального топлива в Navigation
также снимается. Этот модуль не объявляет наземные службы реализованными.

World хранит единственный `station_state_by_site`: слово двери, знаковый
статус и исходную Q31-матрицу/часы. `refresh()` сначала обновляет это
состояние посредством World, затем задаёт тот же кадр Flight. Состыкованный
корабль следует вращению в центре станции. Неподвижный набор треугольников
при неизменных модели/UID/двери повторно не копируется: меняется только
малый кадр. Изменение слова двери запрашивает новую исходную геометрию.

## Загрузка без изменения живого корабля

```gdscript
var candidate_nav = Navigation.new()
if not candidate_nav.restore(saved_navigation):
    return {}
var candidate_world = World.new()
candidate_world.configure(candidate_nav.current())
if not candidate_world.restore(saved_world):
    return {}
var restored = Session.restore_flight(candidate_world, candidate_nav, saved_flight)
if restored.is_empty():
    return {}
var candidate_ship = restored.ship
# Далее кандидат Surface и общие проверки приложения.
```

`restore_flight()` сам создаёт новый Flight. Успех возвращает
`{ok:true, ship, context}`, отказ — пустой словарь. Входные World/Nav
также должны быть изолированными уже восстановленными кандидатами.
Живые модели приложение заменяет только после остальных проверок.

Активная исходная станция требует Flight v5 с совпадающей идентичностью.
Без неё v5 отвергается. Сохранённая завершённая стыковка требует центра
станции, нулевой скорости и нулевой заданной скорости с малыми допусками;
предел 12 м/с для захвата на подходе не используется как разрешение
сохранить уже состыкованный движущийся корабль. Проверка выполняется до
поворота/привязки, которые могли бы скрыть неверный снимок.

## Полный набор исходных корпусов

Поддерживаются корни **69 и 72–80**. Модель69 действительно встречается
в исходной системе `44963608`, порт `site13`. Её ресурсы69/225 извлечены
в отдельный `ffe_special_station_models.json`; опубликованный основной
набор ресурсов сохранён. Загрузка дополнения защищена отдельным mutex.

Все остальные девять корней уже присутствуют в исходных ресурсах.
Модели74/76/77 требуют явной политики восьми нулевых корневых локальных
параметров для статического model compiler. UID и слово двери передаются
как исходные entity-параметры. Это документированный вход современного
статического визуализатора, а не заявление о переносе всего DrawModel.

Восемь корней используют исходную секцию227. У79 и69 интерьер встроен
в корневую программу: рамка дока выводится соответственно из настоящих
граней602–734 и110–160. Отсутствующая секция227 не создаётся. Открытые
и закрытые исходные панели, весь корпус и исходные вложенные программы
сохраняются; центральный маршрут проверяется по этим треугольникам.

В проверенном наборе 4230 допустимых реальных заголовков найдены обычные
порты69/72–78/80. Модель79 закреплена отдельно реальным native-выходом
F892 для специального `port_type=4`; наличие её в этом корпусе заголовков
не утверждается. Никакая запись порта для теста79 не придумана вручную.

## Проверки

Независимый инструмент `rebuild_station_vertices_native.py` выполняет
настоящие F1470/F1478 для всех десяти корней: 240 контекстов, 14 544
вершины, три свежих процесса, обратный порядок и защитные байты.
Проверяются целые координаты, средние kind11 и динамические kind19.
Это отдельная проверка вершин, не native-выполнение всей программы
треугольников или её кадров родительских подмоделей.

Session проверяется на настоящих Flight/Navigation/Geometry, на всех
исходных packed-корнях и на реальных World v4: восемь солнечных станций,
а также процедурные69/74/75/76/77/78. Проверены World-first загрузка,
двери/вращение, очистка наземного контекста, неверные кадры/идентичности,
неизменность живого корабля и отсутствие повторных загрузок полного
набора треугольников в128 последовательных кадрах.

Текущий результат: **391 проверка Session, 50 429 проверок геометрии/
native-координат и402 проверки Flight — без ошибок**.

```sh
python3 tools/rebuild_special_station_models.py
python3 tools/rebuild_station_vertices_native.py
godot --headless --audio-driver Dummy --path . --script tests/test_source_station_session.gd
godot --headless --audio-driver Dummy --path . --script tests/test_source_station_geometry.gd
godot --headless --audio-driver Dummy --path . --script tests/test_source_docking_flight.gd
```

Физический заход использует современный телефонный автопилот и CCD
по исходным твёрдым граням. Оригинальная очередь трафика, разрешения,
вся collision VM и весь исходный ИИ этим контекстом не объявляются
перенесёнными. Здесь также нет измерения FPS на телефоне.

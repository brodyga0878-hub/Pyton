# ZIP-отчёты об ошибках0.11.2

Обновление от5ноября2026, Москва. Кнопка «Отчёт об ошибке / логи» добавлена в обычное меню и графический полёт.

## Как прислать отчёт

1. Откройте «Меню → Отчёт об ошибке / логи».
2. Кратко опишите проблему и как её повторить. При необходимости включите «Добавить сохранение текущего полёта»; по умолчанию снимок не добавляется.
3. Нажмите «Собрать ZIP и сохранить…», выберите «Загрузки» в системном окне Android.
4. Прикрепите полученный ZIP к сообщению в ChatGPT.

При отмене архив остаётся внутри приложения и доступен по кнопке повторного сохранения. Открытие страницы, сборка и экспорт не меняют активный полёт и не перезаписывают игровые слоты. Начальная запись в обычном меню остаётся прежним поведением игры; страница отчёта и потеря фокуса при экспортёре не вызывают дополнительных сохранений.

## Содержимое

Версия сборки/движка/ОС, модель устройства, GPU/драйвер, настройки, текущий режим, координаты/скорость/переходы, последние события и реальные ошибки движка/GDScript с файлами и строками стека. Есть предыдущий сеанс и отметка штатного завершения; незакрытый сеанс не объявляется доказанным сбоем. Описание и, при явном выборе, JSON-снимок полёта включаются в ZIP. Размеры и SHA-256 каждого файла находятся в манифесте.

Ограничены текущий/предыдущий журналы, размер архива и число хранимых ZIP. Неограниченный нативный файловый logger отключён; ошибки и сообщения собираются штатным API Godot Logger с ограничением памяти/диска. Подключение выполняется до построения мира и интерфейса. Ошибки до этой инициализации, системный logcat/tombstone и нативный аварийный дамп не обещаются. Значения локальных переменных, аккаунты, окружение процесса и уникальный идентификатор устройства не собираются.

Android использует встроенный Godot4.6.3 SAF ACTION_CREATE_DOCUMENT и проверенную запись content:// через FileAccess. Плагин, Gradle, INTERNET и широкие разрешения хранилища не добавлены. После копирования ZIP сверяется SHA-256. Маршрут подтверждён исходниками движка; системное окно на физическом S23 Ultra ещё не испытано.

Намеренные тестовые ошибки создаются только в изолированном дочернем процессе и проверяются как данные.

# Последовательный автоматический полёт — 0.26.0

TEST-кандидат **0.26.0-native-autopilot-alpha1 / Android code 51** развивает
отдельное испытание исходной посадки. Статус **PREPUB**: точные APK/source ZIP,
хеши, итоговые проверки, свежая переносимость и проверенные HTTPS-ссылки
закрепляются после завершения и проверки трёх последовательных задач.
Предыдущая опубликованная сборка — [0.25](RELEASE_0_25_0_RU.md).

1. **Автопосадка.** На исходной поверхности вне города включается наведение,
   которое выпускает физические шасси, выравнивает корабль и выбирает
   управляющие команды снижения. Стоянку принимает настоящий F576/F575;
   совпадение видимой высоты с нулём не заменяет исходное касание.
2. **Автоматический взлёт.** Из принятой стоянки выполняется подъём до
   локальной отметки 1 км. Запрос не освобождает стоянку и не перемещает
   корабль до принятого powered-интервала. Шасси убираются после реально
   набранного просвета. Подъём, торможение и конечное удержание используют
   существующие команды полёта, тягу и реактивное топливо.
3. **Переход в космический режим.** Отдельная команда продолжает настоящий
   подъём к области передачи управления. Для дальнего подъёма требуется
   действительно установленная атмосферная защита; её наличие проверяется
   до запуска команды. Переход должен сохранить реально
   достигнутую позу, скорость и время, проверить просвет обычного космического
   защитного поля и сохранить распознаваемый отдельный trial-сеанс после
   выхода из локальной поверхности. Фиксация этого пункта входит в итоговую
   проверку PREPUB-кандидата.

Пауза и открытые окна не двигают автоматический полёт. Ручные команды и
«Тормозить» отменяют наведение. Состояние активной задачи сохраняется с
позой, исходной историей, временем, HP/RNG, топливом и шасси; отдельно
проверяется холодное продолжение. Возврат к прежнему основному полёту
остаётся в меню, испытание использует отдельное хранилище сохранений.

Для воспроизведения ошибки используйте **«Отчёт об ошибке / логи»**.
По выбранной галочке ZIP содержит полный снимок текущего trial-полёта,
включая наведение или космическую фазу. Архив можно прикрепить в чат.

Новое наведение — явный мобильный host-адаптер поверх исходных контакта и
состояния стоянки. Полный исходный F597/AI-автопилот, его оборудование,
VM-callbacks и object bank этим блоком не объявляются перенесёнными.
Поворот скорости при передаче кадра не подразумевает добавление
`omega×radius`: соответствующая политика указывается в контракте.
Вертикальный подъём и переход к космическому полёту **не создают круговую
орбиту** и не доказывают полный исходный F570/F606 выбор кадра.

Обычные поверхность v4 и прогресс сохраняются отдельно. Буквальные
наблюдавшиеся leaf-треугольники остаются ограниченным полем испытания,
а не универсальной сеткой любой планеты. Полнота клона/русификации,
магазинный релиз, запуск на физическом S23 Ultra и FPS ещё не подтверждены.

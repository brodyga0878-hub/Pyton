# Заново реализованная арифметика FFE

`scripts/ffe_math.gd` — новая реализация по оригинальным процедурам. Это **не найденный старый файл проекта**. Оригинальные таблицы извлечены из пользовательского архива отдельным инструментом `tools/rebuild_original_data.py`; код арифметики написан заново и сравнен с независимым исполнением ассемблерных процедур.

## Источники

- `FIRSTENC.EXE`: SHA-256 `d919566140abfc298bc9929bc9141d92526586821f017be1336253a04bca1e72`.
- JJFFE: commit `7e540341d4e09aa3c92877b87d49e7f2c143ad8d` репозитория `videogamepreservation/jjffe`.
- `ffe.asm`: SHA-256 `d4f1b76aa78895d3634b182428e14f36ac57b304e56fedb67a89ee39b5f6873a`.
- `DATA_007977`: 2048 исходных `uint16`, смещение `0x100190` в EXE, SHA-256 4096 байт `1bb88ff59cdc392b0c116d26a7f4ec1b9504fdfe42909f522d5ba9cbfcd02ef0`. Сохранены в `data/ffe_math.json`.

## Реализованный API

| Метод | Источник и поведение |
| --- | --- |
| `integer_sqrt` | F1467: восемь беззнаковых диапазонов, оригинальная LUT и побитовые сдвиги. Вход усекается до 32 бит. Это исходное квантованное приближение, поэтому оно отличается от `floor(sqrt(n))`. |
| `from_uint` | F1489: преобразование беззнакового 32-битного значения в упакованное число, включая исходное представление нуля `0xfff90000`. |
| `multiply` | F1482: знаковое произведение мантисс, арифметический сдвиг, сложение показателей и усечение до двух 16-битных слов. |
| `divide` | F1483: целочисленное деление с усечением к нулю, исходная нормализация и константа `0x007f7fff` при нулевой мантиссе делителя. |
| `add` | F1486: знаковое сравнение показателей, выравнивание мантисс, исходная нормализация и ранний возврат при разнице показателей больше 31. |
| `to_integer` | F1491: исходное поведение при больших показателях, включая маскирование счётчика x86-сдвига. |
| `square_root` | F1463: преобразование показателя и мантиссы, вызов F1467. |
| `fixed_multiply` | F1515: раздельные частичные произведения с промежуточным 32-битным переполнением; обычное 64-битное произведение здесь не равно оригиналу для всех входов. |
| `shift` | Прибавление к 16-битному слову показателя, как в F879/F882; мантисса сохраняется. |
| `period` | Цепочка F879/F882: куб орбиты через F1482, F1483 с массой родителя, F1463, затем множитель мантиссы `0x5edb`. |
| `s16` | Знаковое расширение младшего 16-битного слова, как `MOVSX EAX,AX`, в том числе после произведения в F882/JUMP_003697. |
| `real` | Явное преобразование для отображения: `signed16(M) * 2^(signed16(E)-15)` в `double`. Проверено отдельно через Python `math.ldexp`, включая субнормальные значения и переполнение. |

Упакованное число состоит из **знаковой 16-битной мантиссы в младшем слове и знакового 16-битного показателя в старшем**. Это не формат IEEE float. Исходная арифметика выполняется целыми числами; `real()` не участвует в её вычислениях.

## Независимая проверка

`tools/rebuild_math_native_reference.py` читает точные `ffe.asm` и `FIRSTENC.EXE`, проверяет их SHA-256 и собирает небольшой эталонный процесс для Linux x86-64. В оригинальных процедурах меняется только синтаксис NASM → GAS и ширина стековых слотов для ABI хоста. Ветви и 32-битные целочисленные операции сохраняются. Для `period` эталон вызывает исходные процедуры в последовательности F879/F882; полная фабрика тел F882 в этом тесте не исполняется. Для `shift` проверяется нативное сложение 16-битного слова.

Контроли сохранены в `tests/fixtures/rebuilt_ffe_math_native.json`:

- 54 298 входов F1467: все небольшие значения, переходы индексов всех ветвей LUT, границы диапазонов и 16 384 псевдослучайных 32-битных значения с фиксированным seed;
- 34 220 нативных контролей упакованной арифметики, преобразований, сдвигов и цепочки периода; в том числе отрицательные мантиссы, нулевые делители, переполнение показателя и границы выравнивания;
- 168 независимых проверок преобразования `real()` через `math.ldexp`.

Текущий запуск Godot 4.6.3: **142 987 проверок, 0 ошибок**. В число проверок дополнительно входят те же F1467-входы в знаковом представлении и усечение старших 32 бит.

```bash
python3 tools/rebuild_math_native_reference.py --asm /workspace/ffe-upstream/jjffe/ffe.asm --exe /workspace/ffe-original/FIRSTENC.EXE
XDG_DATA_HOME=/workspace/rebuild-test-state/data XDG_CACHE_HOME=/workspace/rebuild-test-state/cache godot --headless --path . --script res://tests/test_rebuilt_ffe_math.gd
```

Нативный эталон нужен только разработчику. Android-игра исполняет GDScript через нативный Godot и не использует x86-процесс, DOS или эмулятор.

## Что эта проверка ещё не подтверждает

Арифметические примитивы не подтверждают единицы SI, оригинальные эфемериды, эпоху часов, фабрику процедурной галактики или подключение исходного рельефа к отображаемой планете. Нельзя автоматически объявлять исходные `real(orbit)` метрами или период секундами без проверки цепочки единиц и времени. Текущий восстановленный мир использует отдельно обозначенный аналитический адаптер.

Другие утраченные методы FFP не заменены заглушками. В сохранённом `body_initializer.gd` вызов `Math.s16(product) >> 17` соответствует необычной исходной последовательности F882/JUMP_003697: `IMUL`, затем `MOVSX EAX,AX`, затем `SAR EAX,0x11`. Знаковое расширение младшего слова нельзя заменять сдвигом полного произведения. Полная инициализация записей F882 проверяется отдельно от арифметического модуля.

# Полный исходный конструктор записи F882

`scripts/body_initializer.gd` — сохранившаяся реализация из `recovered-history/world_gap_audit/scripts/body_initializer.gd`, снова проверенная после восстановления среды. Логика конструктора сохранена; добавлены комментарии о происхождении и проверенной семантике. Арифметика выполняется через отдельно проверенный `ffe_math.gd`. Это завершённый изолированный модуль этапа 10, **ещё не подключённый к живой физике или процедурной галактике**.

## Источник и независимый эталон

- Пользовательский `FIRSTENC.EXE`: SHA256 `d919566140abfc298bc9929bc9141d92526586821f017be1336253a04bca1e72`.
- JJFFE `videogamepreservation/jjffe`, commit `7e540341d4e09aa3c92877b87d49e7f2c143ad8d`; `ffe.asm`: SHA256 `d4f1b76aa78895d3634b182428e14f36ac57b304e56fedb67a89ee39b5f6873a`.
- Истинная LUT F1467 из EXE: SHA256 `1bb88ff59cdc392b0c116d26a7f4ec1b9504fdfe42909f522d5ba9cbfcd02ef0`.

Новый `tools/rebuild_body_initializer_native.py` исполняет **полный F882**, а также настоящие F1467/F1463/F1482/F1483/F1486/F1489/F1491/F1515. Ни нагрев, ни период, ни RNG-поля не подменены эталонной формулой на Python. Меняются синтаксис ассемблера и ширина стековых слотов для Linux x86_64. Оригинальные указатели функций направлены на настоящие процедуры; буферы и стек находятся ниже 2 GiB. Исследовательский процесс нужен разработчику, Android не исполняет x86 и не использует эмулятор.

Важная проверенная особенность: в EXE по смещению **0x2b367** находятся байты `f76c93040fbfc0c1f811668944bb42`: `IMUL`, затем **`MOVSX EAX,AX`**, затем `SAR EAX,17`. Значит нужно знаково расширить **младшие 16 бит** произведения. Сохранившийся `Math.s16(product) >> 17` верен; замена на сдвиг знакового 32-битного произведения была бы ошибкой. В новой арифметике `s16` явно означает это расширение.

## Что делает API

```gdscript
construct(records, index, parent, multiplier, distance, mass,
          seed_a, seed_b, depth, counter) -> Dictionary
```

`records` содержит 68-байтные `PackedByteArray`; родительские ссылки используют исходную нумерацию со значением 0 для отсутствующего родителя. Входные скаляры ограничены unsigned32, destination — 0–59. Метод возвращает новую запись в `record` и обёрнутый unsigned32 `counter`; исходный массив и записи не меняются. Неверный размер, индекс, родительская цепочка или диапазон дают пустой словарь до вычислений.

Проверены исходные действия F882:

- F1515 с младшим словом расстояния, перевод орбиты в упакованное число и изменение показателя;
- период через куб орбиты, деление на массу родителя, корень и исходный множитель; особая ветвь родителя типа 0;
- исходная фаза, UID, масса, счётчик и байт глубины;
- исходная нулевая эксцентричность, переполнение произведения для наклонения и прибавление ориентации родителя;
- исходное знаковое расширение LOW16 для ориентации/байта вращения;
- обход предков с источниками света, упакованное суммирование и двойной корень для нагрева при исходной температуре меньше 1000;
- сохранение остальных байтов записи, включая неизменяемые конструктором поля модели и имени.

Это операции над исходными записями и числами FFE. Их физические единицы API не переопределяет.

## Проверки

Fixture `tests/fixtures/rebuilt_body_initializer_native.json` — **новая самостоятельная выборка**, не найденный старый fixture. **1424 диагностических контекста** используют четыре реальные исходные записи-шаблона и исходные записи Sol/Earth как основу, с явно заданными диагностическими массами, светимостью и связями. Это не заявления о найденных процедурных системах.

Выборка охватывает destination 0/1/2/3/59, отсутствие родителя и цепочку, тип родителя 0, границы unsigned32 и младшего слова расстояния, обе ветви температуры, нулевой делитель исходной арифметики и переполнение счётчика. В настоящих native-результатах есть **200 нулевых орбит**, **187 изменённых нагревом температур**, **879 ориентаций 0** и **545 ориентаций 0xffff**.

Каждый случай повторён после всех остальных в обратном порядке; три свежих процесса дали одинаковый полный результат. Все 59 посторонних записей каждого контекста остались побайтово неизменны. SHA256 полного native-выхода прямого и обратного прохода: `85784639be22fff5eba7293fa6fca69ef54a4078017cb84c61ff974825c63853`.

Godot 4.6.3: **5723 проверки, 0 ошибок**. Сравниваются все 68 байтов результата каждого случая и счётчик, неизменность входа, происхождение эталона и отказы на некорректных запросах.

## Границы результата

Проверка F882 **не завершает** F881/полную фабрику процедурных тел, классификацию климата/биосферы, исходную эпоху часов, эфемериды, преобразование физических единиц, рельефную привязку F879 или живую интеграцию в `planetary_system.gd`. Исторический вариант F879 с отличающимся сдвигом здесь не вызывается. `planetary_system.gd`, `main.gd` и текущий аналитический адаптер мира этим модулем не меняются.

# Возвращение, посадка и помощь при стыковке — 0.27.0

TEST-кандидат **0.27.0-native-return-alpha1 / Android code 52**, PREPUB.
APK, точный исходный ZIP, итоговые результаты и проверенные ссылки будут
закреплены после финальной проверки текущих файлов.

1. **Обратный переход.** В космической фазе отдельного испытания кнопка
   «К поверхности» возвращает в прежний исходный участок без скачка
   высоты или обнуления скорости. Используются текущая Float64-позиция
   и вращение тела. На границе не расходуются время, корпус или топливо.
2. **Автоматическое снижение и посадка.** «Авто» в космической фазе
   выполняет возврат и включает снижение. На большой высоте скорость
   ограничена 60 м/с; перед поверхностью корабль тормозит, выпускает
   физические шасси и выполняет медленный заход. Посадку принимает
   исходный контакт. Работают ручная отмена, пауза, холодная загрузка
   и полный ZIP-отчёт с текущим сохранением.
3. **Помощь при стыковке.** Для штатной исходной станции показаны
   реальные причины отказа: закрытый проём, скорость относительно
   вращающегося дока, курс, крен и положение корпуса. Запрос открытия
   использует настоящую дверь; существующий автоподход и физические
   критерии стыковки сохранены. Упрощённая подсказка «100 м» остаётся
   только у учебной станции.

Начните с основного полёта: установите атмосферную защиту в службах
станции, затем на исходной поверхности вне города откройте **Меню →
«Испытание исходной посадки»**. После вылета «К поверхности» возвращает
ручное управление, а «Авто» включает возвращение с посадкой. Кнопка
«Вернуться к основному полёту» в меню восстанавливает прежний прогресс.

В основном полёте у станции откройте **Меню → «Подход к доку · условия
стыковки»**. Окно также появляется после неудачной ручной стыковки.
Пока окно открыто, полёт и движение двери приостановлены. Закройте его
для продолжения либо нажмите «Автоподход к станции».

Прямой непрерывный переход из native trial к станции не реализован:
станция использует отдельный кадр основного полёта. Естественная посадка
не открывает станционные службы. Обратный переход поддержан только
для прежнего наблюдаемого участка на высоте 1–30 км; это ограниченное
испытание, а не полная поверхность любой планеты или полный F597/AI.
Круговая орбита автоматически не создаётся. Физический S23 Ultra, FPS,
полнота клона/русификации и магазинный релиз ещё не подтверждены.

Проверка текущих файлов завершена: **107 940 условий / 44 уникальные
группы / 0 ошибок**. Отдельно: **393 Python-теста / 15 модулей**, четыре
настоящих осмотренных desktop-кадра / **584 проверки**, прежний исходный
native-банк **402 случая / 6208 условий**. Повторы и отдельные проверки
не добавлены к функциональной сумме. Реальный ARM64 APK52 технически
проверен: 50 445 743 байта; SHA256
`2615dd12ad27bf344dfe6e87f7cb47d80e4f83fb7073e8200f73e71c18b0ec88`.

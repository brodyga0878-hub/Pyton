# Этап10: исходные планетные классификаторы F883–F887

После проверенного звёздного пути F881 добавлен `scripts/planetary_classifier.gd`: исходная классификация одной 68-байтной записи на ветвях F883–F887, которые завершаются без ещё не перенесённых имён и поселений. Арифметика, температурные пороги, исходные модели/типы и изменения случайного состояния сравниваются с настоящими процедурами.

**Это не полный генератор планет.** Ветка F881 для планет также требует F893 до вызова классификатора; рекурсивный генератор имён и полная фабрика системы ещё не перенесены. Модуль не подключён к `planetary_system.gd`, не меняет живую аналитическую физику и сам по себе не создаёт исходную процедурную галактику.

## Поддержанный контракт

```gdscript
var classifier = preload("res://scripts/planetary_classifier.gd").new()
var candidate = classifier.classify(
    record, callback, mass, population_raw, system_id, seed_a, seed_b)
```

`record` — ровно68 байт; `callback` — один из883/884/885/886/887. Остальные аргументы — исходные unsigned32. `population_raw` соответствует сырому `DATA_008854`; исходные знаковые сравнения выполняются после signed32-интерпретации. Это не современная оценка населения в людях. Масса и температура не переименовываются в SI или градусы Цельсия.

Успех возвращает `ok=true`, новую `record`, новые `seed_a`/`seed_b` и номер исходного callback. Входная запись не изменяется. Все принятые ветви исполняют соответствующие исходные действия полностью; в частности:

- F883: горячие, холодные и промежуточные температурные диапазоны, модели/типы123/124/128, особая модель133 в трёх системах, слово температуры с16-битным переполнением и точный F894 при тёплом диапазоне.
- F884: исходное изменение температуры, каменный тип4/модель121 и проверка ветвей, требующих имени.
- F885/F886: исходные условия допустимого завершения без имён/поселений.
- F887: изменение младшего слова массы на0 и старшего слова на0x38 перед исходной проверкой ветви имени.

Весь контекст `population_raw=0..3` завершается без вызова недостающих помощников. Поддержаны и прочие горячие/холодные либо малонаселённые ветви, если они также завершаются самостоятельно. Отрицательные signed32-интерпретации проверены только как диагностические границы регистра; наличие таких тестов не объявляет их реальными населениями галактики.

Если исходный путь требует ещё не перенесённую функцию, API возвращает `ok=false`, `reason="requires_unimplemented_source_helper"` и `helper_id`. При этом **не возвращаются частично изменённая запись или промежуточные seeds**. Вызывающая сторона не может случайно принять незавершённую классификацию за законченный мир. Особые прямые вызовы F892 и вызовы F893 проверены независимо. Ветвь F891 обычно находится после F893 и пока недостижима до более раннего отказа.

Неверный размер записи, callback или числовое значение возвращают пустой словарь. Валидация и отказ атомарны: caller-owned данные не меняются.

## Независимый native-контроль

`tools/rebuild_planet_classification_native.py` компилирует и исполняет настоящие F883–F887 и F894 на host x86_64. Исходные 32-битные вычисления сохранены; адаптированы только ABI и ширина host-слотов стека.

F891/F892/F893 в исследовательской обёртке являются **невозвращающимися границами**, а не заглушками с выдуманным результатом. Достигнутый помощник фиксируется, после чего wrapper покидает callback и начинает следующий контекст. Частичная запись из этого случая не записывается как эталон законченного результата. Принятые случаи выполняют полный исходный callback с настоящим RNG и без этих границ. Ни ELF, ни исполнение x86 не требуются Android-игре.

Проверенные источники:

- `FIRSTENC.EXE`: SHA-256 `d919566140abfc298bc9929bc9141d92526586821f017be1336253a04bca1e72`.
- JJFFE `videogamepreservation/jjffe`, commit `7e540341d4e09aa3c92877b87d49e7f2c143ad8d`.
- `ffe.asm`: SHA-256 `d4f1b76aa78895d3634b182428e14f36ac57b304e56fedb67a89ee39b5f6873a`.

Новая выборка содержит **3060 native-контекстов**: 2224 завершённых классификации и836 случаев отказа по настоящему пути. Для принятых сравнены все68 байт записи, оба RNG-слова и неизменность входа. Для остальных проверяется реальный первый недостающий помощник: F893 —818, F892 —18. F891 не объявляется покрытым.

Принятые случаи по callback: F883 —486, F884 —400, F885 —438, F886 —451, F887 —449. Покрыты температурные пороги, переполнения16/32 бит, знаковые границы контекста, случайные значения с закреплённым seed, индексы0/1/59 и специальные UID космопортов.

Каждый случай исполнен после всех остальных в обратном порядке; три свежих native-процесса совпали. Все59 посторонних записей и индекс назначения не изменились. Повторный запуск генератора воспроизвёл fixture побайтно.

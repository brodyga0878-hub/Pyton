# Проверка графического обновления

В `tools/validate_rebuild.py` добавлены три обязательные группы: `graphics_ship`, `graphics_environment`, `graphics_integration`. Обычный общий запуск включает их вместе с прежними группами; этот документ фиксирует отдельный целевой прогон после изменения Main и графики.

## Фактически выполнено

Godot **4.6.3**, **1408 проверок, пять пройденных групп, ноль ошибок**. Каждая из выбранных групп исполнена один раз в этой партии. Ошибок скриптов, движка и диагностик утечки ресурсов не было.

| Группа | Проверок | Область |
|---|---:|---|
| `graphics_ship` | 108 | Подробный корпус, габариты и нормали, кэш меша, повторная конфигурация, выхлоп и шасси |
| `graphics_environment` | 1136 | Геометрия станции, свободный подлёт, детерминированные астероиды, свободный вид на планету, дистанция и уровни детализации |
| `graphics_integration` | 41 | Настоящий Main, вход и возврат через меню, сохранность исходного полёта и файлов, защита при отказе записи, управление, качество и возврат в Новую Москву84 |
| `app_transitions` | 54 | Повторная проверка изменённого Main: блокировки переходов, продолжение сохранённого маршрута и асинхронный вход в город |
| `save_touch` | 69 | Повторная проверка общего сохранения и независимых касаний |

Команда из корня проекта:

```sh
python3 tools/validate_rebuild.py \
  --suite graphics_ship --suite graphics_environment \
  --suite graphics_integration --suite app_transitions --suite save_touch \
  --summary build/graphics-validation.json --output build/graphics-validation
```

Отчёт — `build/graphics-validation.json`, логи — `build/graphics-validation/logs/`. Там записаны реальные команды, SHA-256 файлов тестов, версия Godot, время и счётчик каждой группы. Интеграционные группы Main получают `-- --rebuild-capture`: пользовательский полёт не загружается. Группа графического режима записывает только собственные временные тестовые файлы и затем удаляет их.

Для проверки отказа сохранения тест создаёт в своём каталоге обычный файл на месте ожидаемого каталога. Настоящий Main должен отказаться от входа в графический полёт, сохранить исходные модели и содержимое файла, оставить меню открытым и показать настоящую ошибку. При успешном входе проверено, что полёт, меню, пауза, импорт/экспорт и автоматическое сохранение демонстрации не меняют байты исходных тестовых слотов. После возврата возобновляется именно приостановленный гиперпереход; исходный городской Surface и его визуальный узел также сохраняются.

## Границы результата

Сумма **1408** относится только к этой партии. Она не прибавляется к старому отчёту **212493**: два регрессионных набора уже присутствовали в прежнем отчёте. Остальные старые группы в этой партии не перезапускались.

Общий JSON имеет статус `passed_with_coverage_limitations`, поскольку валидатор сохраняет общую пометку об отсутствующем историческом `model_vertices_reference.json`. Все пять выбранных групп реально прошли; пропущенных групп внутри этой партии нет. Новый корпус и окружение являются авторским оформлением; эти тесты не доказывают перенос всех57 оригинальных кораблей, добычу или столкновения с декоративными астероидами.

Headless-проверки не подтверждают внешний вид шейдеров. Настоящая отрисовка сцены через GLES и скриншоты из `tools/capture_graphics.gd`, полный игровой smoke и техническая проверка APK выполняются отдельно. Измерений FPS, нагрева и жестов на физическом Samsung S23 Ultra пока нет.

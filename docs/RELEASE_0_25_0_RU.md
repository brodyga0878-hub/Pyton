# Ручное испытание исходной посадки — 0.25.0

TEST-кандидат **0.25.0-native-landing-alpha1 / Android code 50** соединяет
проверенные исходные фрагменты рельефа с ограниченным ручным циклом контакта.
Статус — **PREPUB**: итоговые проверки, точные APK/source ZIP, их SHA,
переносимость и постоянные ссылки ещё закрепляются. Последняя опубликованная
сборка — [0.24](RELEASE_0_24_0_RU.md).

На исходной поверхности вне города и подземного ангара выберите
**Меню → «Испытание исходной посадки»**. Игра подготовит отдельную копию
полёта в 50 м над ограниченным участком исходной поверхности. Основной
полёт остаётся доступен через команду возврата в меню. Испытание использует
свои сохранения и отдельную команду загрузки.

Выпустите шасси и осторожно снижайтесь вручную. При принятом контакте
сохраняются исходное состояние стоянки и raw-история; отсутствие касания
не паркует корабль. Для взлёта используйте **«Взлететь»** и доступную тягу
вверх. Запрос взлёта сам по себе не переносит корабль на другую высоту.

Видимая поверхность состоит из тех же буквальных Float32-треугольников,
которые выдаёт высотный provider. Их координаты и индексы не деформируются;
материал и нормали отвечают только за отображение. Перекрывающиеся
посещённые фрагменты остаются настоящими отдельными треугольниками.
Верхний покрывающий фрагмент выбирается доказуемым геометрическим порядком.
Целочисленная высота F1876 и эта высота mesh не объявляются тождественными.

Состояния корабля, source-навигации/HP, топлива, часов, шасси и контакта
подготавливаются вместе. Неудачная проверка шага оставляет прежних владельцев
состояния. История контакта и холодное восстановление имеют отдельные
проверки; сохранённая стоянка не должна повторно применять урон.

Для ошибки используйте существующее **«Отчёт об ошибке / логи»** и отправьте
полученный ZIP в чат. Сохранение текущего полёта добавляется только при
явном выборе соответствующего пункта.

Автоматическая посадка и полный автоматический перелёт/выход на орбиту
в новый цикл пока не подключены. Обычный режим игры сохраняет прежнюю
поверхность; экспериментальный участок не выдаётся за универсальную
поверхность любой планеты. Полный исходный object bank, все VM-callbacks,
полнота клона/русификации, FPS, запуск на S23 Ultra и магазинный релиз
пока не подтверждены.

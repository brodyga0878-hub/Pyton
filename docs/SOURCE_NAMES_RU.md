# Исходные имена планет и поселений

`scripts/source_planet_names.gd` переносит именование F893 и применимые
текстовые ветви F791. Завершены все категории, с которыми F893 вызывается
из исходных F881/F883–F887/F891/F892: **6, 7, 8, 9, 10**. Это имена
наземных и орбитальных портов и именованных планет. Глобальное состояние
генератора F894 модуль не расходует: исходная F791 использует отдельную
пару слов, производную от UID записи, и локальную F921.

Вариант обозначен `jjffe-7e54034-names-original-text`. Код закреплён за
JJFFE `7e540341d4e09aa3c92877b87d49e7f2c143ad8d`, таблицы имён берутся
из загруженного `FIRSTENC.EXE`, SHA-256
`d919566140abfc298bc9929bc9141d92526586821f017be1336253a04bca1e72`.
Это отдельно проверенный вычислительный модуль, а не сам по себе полная
процедурная галактика или завершённая русификация.

## API

```gdscript
const Names = preload("res://scripts/source_planet_names.gd")
var named = Names.rename(record68, category, language)
var generated = Names.generate(category, uid)
```

Все методы статические. `rename` принимает одну 68-байтовую исходную
запись, категорию 6–10 и исходный языковой флаг u32. Она возвращает новый
`record`, исходные `name_bytes`, число байтов `end_offset`, фактически
записанный префикс `write_bytes`, применённую категорию и вариант.
Переданная запись не изменяется. При языке 3 категории 6/7 переходят
в 17, а 8/9 — в 16, как в F893. Это исходная языковая ветвь, а не
перевод полученного названия на русский.

`name_bytes` включает конечный NUL. `end_offset` соответствует указателю
за этим NUL. `write_bytes` может быть длиннее видимого имени: исходные
временные операции могут оставить байты после нового NUL. `rename`
сначала устанавливает `record[0x3f] |= 0x80`, затем копирует весь реально
записанный префикс, сохраняя исходный порядок операций.

`generate` дополнительно воспроизводит текстовые категории F791 0–22.
Категории 0/15/21 дают исходное `????`; 1–5 — исходные личные имена,
6–14 и 16/17 — имена с шаблонами, 18–20 — буквенно-цифровые обозначения.
Третий параметр `generate` — необязательное NUL-терминированное сырое
имя игрока для категории 22; по умолчанию оно пустое. **Это не параметр
языка**. В ветви личных имён сохранено изменение JJFFE выбора пола;
полное равенство этой ветви DOS не заявляется.

Категории 23–25 запрашивают имена модели, тела или станции по внешнему
игровому контексту. Эти обращения относятся к другим модулям и
отклоняются; они не являются путями F893 процедурного конструктора.
Неверная длина записи, дробное/нечисловое значение, значение за пределами
u32 и небезопасная длина записи также дают пустой словарь до изменения
входных данных.

Для генератора систем доступны чистые помощники:

```gdscript
var rng = Names.random_bounded(first_u32, second_u32, bound_u32)
var surname = Names.surname(first_u32, second_u32)
var bytes = Names.expand_table_index(raw_table, index, optional_var3_bytes)
```

Первый точно повторяет F921, включая вращения и усечение 32-битного
произведения. Второй повторяет F793 и возвращает имя и оба новых слова.
Последний обрабатывает исходные байты таблицы и используемый именами
код FF3016 — подстановку четвёртой строковой переменной. Остальные
FF-модули и произвольные команды журнального форматирования не получают
вымышленных результатов. Необязательная замена таблицы в `surname`
является параметризованным помощником; независимые контроли F793
используют его исходную таблицу по умолчанию.

## Происхождение таблиц и исходные особенности

В `data/ffe_planet_names.json` находятся **510** указателей/строк,
а не искусственно дополненная таблица из 512 имён. Маскирование индекса
`& 0x1ff` в F800 само по себе не доказывает существование 512 записей.
Проверенные ветви генератора обращаются только к существующим строкам.

Текстовый блок занимает 3866 байт, начиная со смещения EXE 824828.
Блок смещений/диапазонов имеет 120 байт со смещения 824708. Таблица
сложна тем, что метки нескольких массивов перекрывают области других
таблиц; сохраняются действительные байтовые смещения, а не современная
перестройка предполагаемых массивов.

В закреплённом `ffedat.asm` есть одно изменение относительно EXE:
байт 1354 текстового блока заменяет исходное `du Pr\x83s` на `du Pres`.
Новый ресурс сохраняет байт EXE и отдельно записывает hash закреплённого
текста и эту единственную разницу. Кодировка остаётся исходной байтовой:
она не подменяется UTF-8, CP437 или произвольной транслитерацией.
Русское отображение и редактура относятся к отдельному слою.

Другой существенный случай — исходная строка `M[nich`. Вставка через
FF3016 проходит настоящие F1343/F77/F76. Последовательность `[ni`
не совпадает с известной журнальной командой: F76 потребляет `ni`,
оставляя `[`, и получается `M[ch`. Нативный контроль исполняет этот
путь целиком, включая настоящий F76 и блок ключевых слов.

При этом сначала в целевой буфер записывается `M[nich`, затем поверх
него — более короткое `M[ch`. Старые байты после нового NUL остаются.
Например, имя `Fortress M[ch` сохраняет за NUL хвост `h\0` от временной
строки. Совпадения видимого имени недостаточно: тест сравнивает весь
результирующий 68-байтовый record и полный префикс записей буфера.
Эти особенности не исправляются незаметно при переносе.

## Независимые проверки

`tools/rebuild_source_names_native.py` извлекает настоящие процедуры
F893/F791–F800/F921 и используемые F76/F77/F93/F94/F1343/F1347/F1348/F1364.
Выполняются их инструкции с адаптацией только host ABI и CRT-копирования.
Нативные обращения вне проверяемого домена завершаются без возврата;
недоступные глобальные данные журнальных протоколов привязаны к
недоступному адресу, чтобы ошибка области не дала правдоподобный текст.
Генератор имён на Android остаётся обычным GDScript ARM64 и не запускает
x86 или исследовательский ELF.

Fixture содержит **2222** контекста: прямые имена F791, переименование
полных записей F893, отдельную F921 и отдельную F793. Три свежих
процесса и обратный порядок дают одинаковый результат. Проверены
защитные участки записи и выходного буфера, полный record, оба слова
локального RNG, конечные указатели и временные хвосты после NUL.
Godot 4.6.3: **9550 проверок, 0 ошибок**.

```sh
python3 tools/rebuild_source_names_native.py
godot --headless --path . --script tests/test_source_planet_names.gd
```

Готовые ресурсы и независимый fixture входят в проект. Перегенерация
требует закреплённых исследовательских ASM, ffedat и исходного EXE.

# Новый графический корпус корабля

`ship_visual.gd`, `ship_hull.gdshader`, `ship_exhaust.gdshader`, `ship_halo.gdshader` — вновь созданное процедурное оформление. Основной образец — широкий клиновидный корпус «Кобры» с поднятой кабиной, раздельной бронёй, каркасом, соплами, радиаторами, трубами, оружием и маркировкой. Это собственная адаптация, а не извлечённая оригинальная геометрия FFE и не готовый каталог57 лётных кораблей.

## Реальная реализация

- Высокий профиль основного корпуса:7534 треугольника без шасси,12 групп материалов в одном ArrayMesh. Это замена прежних10 треугольников корпуса. Три посадочные опоры объединены ещё в один меш с тремя материалами.
- В сцене всего5 непосредственных узлов: общий корпус, два выхлопа, маркировка и общее шасси. Два небольших геометрических ореола являются дочерними узлами выхлопов. Детали не превращены в сотни отдельных MeshInstance.
- Общая геометрия и неизменяемые материалы кэшируются для трёх адаптированных профилей и уровней качества. Выхлопы имеют отдельные экземпляры материалов, меняются по тяге и времени.
- Нос смотрит по−Z, двигатели — по+Z. Высокая «Кобра» вписывается в установленный размах42м; твёрдая геометрия не расширяет прежнюю лётную область. Свечение/выхлоп не являются коллизией.
- Материалы имеют отдельные металлические/окрашенные/стеклянные свойства. Процедурная микрофактура цвета/шероховатости приглушается по производным пикселя для уменьшения мерцания вдали.
- Выхлоп — реальная геометрия с анимированным шейдером. Это не изображение, добавленное к скриншоту.
- «Игл» и челнок используют адаптированные пропорции этой оформленной основы. Отдельные исходные модели, анимации и полный каталог остаются этапом9.

Публичный API: `configure(profile)`, `set_quality(0..2)`, `set_thrust(0..1)`, `set_landed(bool)`. Изменение материалов не меняет физику, размеры корабельного профиля, груз, оборудование или сохранения.

Шасси выдвигается при посадке и точно доходит до существующей физической плоскости `span*0.14+2.0` для всех трёх адаптированных профилей. Это устраняет визуальное зависание без изменения сохранений или лётной физики. Свечение сопел реализовано двумя маленькими прозрачными плоскостями с обычным тестом глубины; экранный bloom не заявляется.

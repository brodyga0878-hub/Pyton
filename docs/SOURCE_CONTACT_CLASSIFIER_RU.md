# Исходные столкновения — 17 ноября 2026 года

Контрольная точка **contact-classifier-core-2026-11-17** соединяет исходный
перебор объектов F569/F570 с целой процедурой контакта F575, настоящей
сферической проверкой F577 и реакцией пары F578 оригинальной DOS-версии.
Это развитие проверяемого ядра. Новые модули ещё не подключены к Main;
устанавливаемая игра остаётся **0.28 / Android code 53**.

## Что перенесено

`source_contact_classifier.gd` выполняет полный порядок решений F575:
грубое отсечение по исходным 64-битным словам, выбор геометрической ветви,
проверку сферы, исправление положения и реакции игрока или другого объекта.
Абсолютные координаты записываются в буфер вызывающей функции даже при
раннем выходе. Для нормали сохраняется отдельный знаковый вектор. Тип
столкновения сбрасывается после грубой проверки; прежние флаги до неё
сохраняются. Исправление положения предшествует проверке типа NPC.

`source_pair_response.gd` переносит настоящую DOS F578. В JJFFE эта
процедура существенно заменена. Оригинал либо уменьшает и разворачивает
скорость одного объекта, либо присваивает паре среднюю скорость с исходным
знаковым переполнением. Запросы урона рассчитываются из текущего состояния.
После первого F953 исходник повторно читает HP и индекс участника; эти
чтения сохранены. Сам движок урона и уничтожение объекта не исполняются
новым модулем: их ответы должны быть предоставлены на точной границе.

`source_contact_scan.gd` соединяет F569/F570 с этим классификатором.
Объекты проверяются в исходном порядке. Действительные преобразования
вращающегося кадра, cooldown и кеши сохраняются. Для продолжения исходного
F1033 формируется ответ с проверяемым входным телом, флагами, высотой и
ссылкой на фактический объект. Ответ другого или прежнего тела отклоняется.
Если исходник оставил старую ссылку на не представленный в банке слот,
raw-результат сохраняется точно, но ответ для F1033 не создаётся.
Квитанция явно отмечает `contact_boundary_available=false`.

`source_contact_scan_state.gd` владеет полными raw-записями объектов,
флагами банка, окном Root, collision-globals и параметрами вызова. Подготовка
операции выполняется на копии. Commit повторяет её и проверяет владельца,
ревизию, квитанцию и результат. Холодная загрузка проверяет последнюю
операцию повторным исполнением. Координаты, остатки и кеши сохраняются
байтами без пересчёта через метры и числа с плавающей точкой.

В прежней `source_frame_dispatch.gd` добавлен необязательный режим остановки
перед очередным вызовом F575. Обычный вызов сохраняет прежнее поведение.
Это единственный изменённый runtime-файл предыдущей контрольной точки:
остальные **504 из 505**, а также все **475** файлов опубликованной игры,
должны оставаться побайтно прежними.

## Границы геометрии

Полная маршрутизация F575 не завершает универсальную геометрию игры.
F576 для произвольных моделей пока требует явного наблюдаемого ответа
с полными входными и выходными записями. Недостающая проверка геометрии
останавливает операцию без изменения живого состояния.

Уже существуют ограниченные проверки естественных поверхностей и исходные
вершины/нормали моделей. Ещё нужны общая программа столкновений F582,
условные записи оборудования, списки плоскостей F583, вложенные модели
и преобразования F580, а также извлечение полных collision-программ.
Программы отрисовки не подменяют эти данные.

D8696–D8707 находятся вне окна GameRoot. D8702 — отдельная ссылка контакта,
а не Root CC. Индекс игрока берётся из Root C0; после наблюдаемого изменения
он возвращается в те же байты. В снимках используются индексы объектов
вместо адресов памяти. Перевыделение слота на границе F953 не поддержано:
изменение идентичности записи отклоняется.

Исходные дескрипторы доступны для 149 моделей. Если ветвь требует
неподдержанного дескриптора, она отклоняется без выдуманного радиуса.
Невозможный ответ F576, который заставил бы оригинал прочитать
неинициализированный локальный операнд, также отклоняется.

## Проверка

Источник FIRSTENC.EXE: SHA256
`d919566140abfc298bc9929bc9141d92526586821f017be1336253a04bca1e72`.
Целые процедуры сверяются с DOS-инструкциями. Независимый эталон исполняет
эти инструкции через документированный ELF64 ABI-адаптер; это не запуск
неизменённого IA32-файла. Python составляет пакеты и сравнивает байты,
но не рассчитывает ожидаемую физику.

Для F575 включены 392 native-сценария, в том числе последовательные
вызовы; для F578 — 320. Сравниваются целые записи, векторы, глобальные
слова и порядок вызовов. Общие процедуры разных доказательств не считаются
уникальными повторно. Итоговый прогон: **184 129 проверок / 25 уникальных наборов / 0 ошибок**.
Четыре новых набора — **8204**. Native-примеры и повторы переносимости
к этому числу не прибавлены. Отдельные 32 композиционных примера
соединяют настоящие F569/F570 и F575; проверены весь банк,
80 вызовов контакта, преобразования кадра и кеши.
Сводка: `validation/contact-classifier-2026-11-17/final-regression/summary.json`. Проверка Android и производительности S23 Ultra
в эту контрольную точку не входит.
